# タイトル画面

2026-10-19、ユーザーが背景07を了承しタイトル制作を依頼。タイトル画面は仮実装。作品名・英字は将来のロゴが入る領域の仮表示とし、`TitleScreen`の`logoSrc`で文字表示をロゴ画像へ差し替えられる。ロゴ自体は未制作。文字・UIは背景へ焼き込まない。背景07は `src/assets/images/ui/title-office-night.png` へ移動し正本を一本化。追加の画像生成なし。

## 動作

- 通常起動: タイトル画面。上部に仮の作品名・英字、下部中央にNEW GAME／CONTINUE／SETTINGSを横並びのアイコン＋短いラベルで表示。アイコンは既存のSVG描画方式を拡張し、ラベルと読み上げ名を維持。
- NEW GAME: 第1話の導入先頭から開始。既存の保存枠を消去しない。本編開始前はStoryPlayerをマウントせず、背面の進行・オートセーブを起こさない。
- CONTINUE: 既存のAUTO・手動3枠を選ぶ。空枠は選択不可、保存なしは説明表示。`readSlots`／`loadSlot`を使い、旧保存の移行・復元検査・保存枠ごとの履歴を引き継ぐ。破損データはエラー表示し、上書きしない。復帰ノードを初期状態としてマウントし、復帰だけではオートセーブしない。
- SETTINGS: 既存のスライダーで文字速度4段階、BGM/SE音量0〜100。保存キーは本編と共通。音の再生を追加したものではない。
- 各ダイアログはEscapeまたは戻るで閉じ、操作元メニューへフォーカスを戻す。Tab/Enterで操作可能。
- 本編MENUの「タイトルに戻る」から確認を表示。「保存していない進行は失われます」と説明し、初期フォーカスは「戻らない」。EnterまたはEscapeで取り消せ、明示的に「タイトルに戻る」を選ぶと本編をアンマウントしてタイトルへ戻る。確認中はMENUによる進行停止を維持。既存のセーブ・設定は保持し、再開用の初期状態・履歴・プレビューをクリアする。次のNEW GAMEは先頭・履歴なし、CONTINUEは保存枠から復帰。
- 開発サーバーの`?dev=1`のみ本編直行を維持。通常の`?scenario=...`は指定シナリオのタイトル画面から開始する。既存ブラウザーテストの本編前提URLには`?dev=1`の指定が必要。

GameState・SaveData v2・保存枠の形式・シナリオ本文・既存本編背景は変更しない。作品選択・終了画面・BGM再生・本ロゴ制作は今回の対象外。参照: README、PC UI仕様、保存枠仕様、背景制作記録、今回のユーザー指示。

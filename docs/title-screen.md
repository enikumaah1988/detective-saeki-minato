# タイトル画面

2026-10-19、ユーザーが背景07を了承しタイトル制作を依頼。添付例の中央タイトル・英字・縦並びメニューをReact/CSSで実装。文字・UIは画像へ焼き込まない。背景07は `src/assets/images/ui/title-office-night.png` へ移動し正本を一本化。追加の画像生成なし。

## 動作

- 通常起動: タイトル画面。「探偵 佐伯湊」「DETECTIVE SAEKI MINATO」、NEW GAME／CONTINUE／SETTINGSを中央表示。
- NEW GAME: 第1話の導入先頭から開始。既存の保存枠を消去しない。本編開始前はStoryPlayerをマウントせず、背面の進行・オートセーブを起こさない。
- CONTINUE: 既存のAUTO・手動3枠を選ぶ。空枠は選択不可、保存なしは説明表示。`readSlots`／`loadSlot`を使い、旧保存の移行・復元検査・保存枠ごとの履歴を引き継ぐ。破損データはエラー表示し、上書きしない。復帰ノードを初期状態としてマウントし、復帰だけではオートセーブしない。
- SETTINGS: 既存のスライダーで文字速度4段階、BGM/SE音量0〜100。保存キーは本編と共通。音の再生を追加したものではない。
- 各ダイアログはEscapeまたは戻るで閉じ、操作元メニューへフォーカスを戻す。Tab/Enterで操作可能。
- 開発サーバーの`?dev=1`のみ本編直行を維持。通常の`?scenario=...`は指定シナリオのタイトル画面から開始する。既存ブラウザーテストの本編前提URLには`?dev=1`の指定が必要。

## 範囲

GameState・SaveData v2・保存枠の形式・シナリオ本文・既存本編背景は変更しない。タイトルへ戻る本編メニュー・作品選択・終了画面・BGM再生は今回の対象外。参照: README、PC UI仕様、保存枠仕様、背景制作記録、今回のユーザー指示。

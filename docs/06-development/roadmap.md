# 制作の順序と未完了事項

現在の実装・採用状態は[制作状態](production-status.md)、要件と着手許可は[GitHub Issues](https://github.com/enikumaah1988/detective-saeki-minato/issues)とユーザーの依頼で確認する。以下は既存方針の整理で、新機能の採用や担当への依頼ではない。

1. **Issue #198**：Phase 2-Aで現行文書・入口・正本を整理しレビュー。マージ後に2-Bの素材・JSON・ツール配置を改めて着手判断する。Phase 3の運用ルール整備も別のレビュー単位にする。
2. **#198完了後**：既存status:ready 14件の順序を破棄せず、#50の喫煙時独白から再開する。自動実装せず、その時点のラベル・実装・依存関係と依頼範囲を確認する。
3. **作品の完成確認**：原稿と組み込みの差分、人による所要時間・流れ・推理難易度、素材の正式採用、PC／スマホ・他ブラウザーの検証・配布条件を確認する。未採用の音・演出・新機能の候補を、この順序表だけで確定しない。

旧マイルストーン・タスク候補・担当と当時の状態は[旧ロードマップ](../99-archive/development/roadmap.md)と[旧ADV進行管理](../project-management/ADV進行管理.md)へ保持する。旧資料にある履歴500件、未接続マップ、古い役割・作業フォルダー等を現行仕様にしない。固有の未完了提案の確認が終わっていないため、これらの原文を削除していない。

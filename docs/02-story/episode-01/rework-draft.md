## 脚本設計で合意した方向性

- **部の境界**：移動や話題転換ではなく、事件の重大な発見・認識の変化を契機にする。
- **部の締め**：転換点を受け、湊の短い心の声（目安2～3文）で余韻を残して暗転・次部へ。独白の文面はすべて仮稿。
- **シーンの粒度**：同じ場所で自然につながる日常・来客・依頼・受諾は一続きにする。場所・時間・操作・劇的転換の違いがある場合に分割を検討。

## 共通操作方針：「考える」の位置づけ（2026-10-23合意、実装未反映）

- **「考える」**はヒントコマンドではない。湊がこれまでの会話・調査で得た情報を振り返り、分かっていること・未解明のことを認識し、次にどう動くかを自身の言葉で考える内面描写とする。
- 進行状況や取得済み情報に応じて独白を変える。まだ得ていない情報や真相を先取りしない。正解の手順を直接指示するナビゲーションにはしない。
- **「考える」は常時表示せず、シナリオ上で湊が情報を振り返り次の行動を考える必要がある場面にだけ表示する。** 当該場面の必要な会話・調査アクションが完了したら出現し、実行すると既存の喫煙CGと独白を挟んでシナリオを進める。会話フェーズの切替ごとに必ず出すものではない。
- **「整理する」**は複数の情報・証拠を照合し、矛盾や新事実を導く操作として区別する。
- S01での例：『5日の朝、直人はいつもどおり家を出た。だが、会社には出勤していない。本人とも連絡がつかない……。まずは、家を出る前の様子をもう少し確かめたい。』（台詞は仮稿）

## 思考演出案：「考える」「整理する」の挿絵（2026-10-23検討）

- **考える**：湊の心の声で既知情報を振り返り、次の行動を考える。ヒント画面にはしない。
- **整理する**：挿絵を見せながら、複数の情報・証拠の照合や推論を行う。必要な場合のみ選択UIを重ねる。

## 話題の段階切替（2026-10-23合意した方向性、詳細未確定）

- 「話す」のサブコマンドは**同時表示6件程度はUI検討上の目安であり、固定の上限ではない**。シナリオの自然さと操作性を優先し、話題数は場面ごとに調整する。PC・スマホ横画面でスクロールや窮屈さが生じないよう配慮するが、数合わせのために不自然な分割はしない。
- 会話の中で話題が増えるB案を採用。ただし無制限に追加せず、関連する話題を**会話フェーズ単位**にまとめる。
- その会話フェーズで必要な情報を聞き終えたら、湊が「ここまでの話を踏まえると、次はこういうことを聞こう」と**短い内面描写でまとめる**。その後、同一シーン内で次の会話フェーズへ移り、新しい話題群に切り替える。場所・背景・シナリオの場面は変えず、暗転も必須にしない。この切替に「考える」は必須ではない。
- **会話フェーズの切替と「考える」の発生は別々の条件で設計する。** 通常の会話進行で話題群を切り替えてよく、「考える」を毎回要求しない。「考える」を置く場面に限り、必要な会話・調査完了後に表示し、その実行を当該場面の進行条件とする。

## S01ゲーム進行設計・第1案（2026-10-23、検討中）

- **自動導入**：事務所で湊と澪のコーヒーの掛け合い。あかり来訪、自己紹介、兄の失踪相談まで自動進行。
- **プレイヤー操作「話す」**：あかりへの事情聴取。通読稿をもとに、①最後に会った朝、②連絡が途絶えた経緯、③勤務先と会社への確認、④普段の兄、⑤警察への相談、を話題候補とする。**5件は脚本から生じた仮のまとまりで、固定件数ではない。**
- **話題の出現**：最初からすべて並べる必要はない。会話に応じて派生話題を追加するB案。順序が違っても台詞が矛盾しないよう設計する。具体的な解放フラグと必須／任意の確定は未了。
- **依頼受諾**：必要な事実が揃ったら自動会話へ。直人の写真、あかりの連絡先、料金・調査方針を扱う。写真・連絡先は自然なやり取りで取得する。
- **退室後**：澪との短い会話を挟み、必要な聞き取りと依頼受諾が完了している場合に限り**「考える」が出現**。事情聴取中は表示しない。

- **S01終端**：澪に東成ビルサービスの所在地を確認してもらい、湊が出発準備。ここでS01終了。次の移動先をプレイヤーが選ぶ。自動的に会社へ移動しない。

8. 湊は事件性を断定しない。宮原に連絡先を渡し、直人が現れたら連絡を頼む。
9. 管理記録や三崎の報告書の詳細は後続シーンに温存。

**制作意図**：宮原を都合のよい情報提供装置にしない。S02で全証拠を出さず、再訪に意味を持たせる。2024年の事故を「半年前」などに変更しない。

## 4. S03：警察との接点・日常（展開・人物関係は合意済み、台詞はドラフト）

### S03-01 事務所・夕方
- 湊が澪に宮原の証言、2024年の三崎死亡、直人が調べていた様子を報告。
- 澪は警察の知人・奥村を提案。
- 掛け合いの基調：
  - 澪「もしかして、奥村さんですか？」
  - 湊「ああ」
  - 澪「また怒られませんか？」
  - 湊「何もしてないだろ」
  - 澪「まだ、ですけど」

### S03-02 奥村への電話
- 旧知の自然な軽口。湊は2024年の事故について相談。
- 奥村は捜査資料を開示できないこと、当時の担当ではないことを明確にする。
- 警察署で会うことに。移動先解放。

### S03-03 警察署
- 奥村と湊は長年の信頼があり、遠慮のない会話ができる。
- 会話候補：「2年前の死亡事故」（必須）／「事故として処理された経緯」（必須）／「高瀬直人について」（任意）／「奥村の見解」（必須）。
- 奥村は、事故と失踪を結びつける根拠がまだ弱いと指摘。
- まず直人の安否と足取りを優先し、妹には警察への相談も勧めるよう伝える。
- 具体的証拠が出たら連絡するよう求める。
- **課題**：警察資料を漏らさず、会話に調査上の意味を持たせること。奥村の助言は現状、方向付けが中心。後で改善可能。

### 瀬川初登場
- 奥村の部下として書類を届けるなど自然な用事で現れる。
- 湊を「捜査に関係のない民間の方」と見て、滞在や情報共有に嫌味を言う。
- 「我々は、探偵の方とは違って、組織として責任を負っていますので」のような**職業的優越感**を滲ませる。
- 奥村は「俺が話を聞いている」と制止する。
- 湊は「間違ったことは言ってませんよ」と受け流す。
- 瀬川は無能でも悪党でもなく、警察官としての正当な職務意識が高圧的に現れる人物。
- **奥村＝信頼と友情、瀬川＝評価と緊張感**。瀬川は第1話で急に改心しない。将来、湊の実力を徐々に認めても、公私の距離と警察官の誇りは残す。

**会話の方向性（採用されたニュアンスを示す例）**
> 瀬川「……まだいらしたんですか」  
> 奥村「なんだ、その言い方は」  
> 瀬川「捜査に関係のない方が、長くいらっしゃるので」  
> 湊「そろそろ失礼するところですよ」  
> （後で）奥村「悪いな、佐伯」  
> 湊「いえ。間違ったことは言ってませんよ」

### S03-04 事務所・夜
- 澪と奥村・瀬川について会話し、事件の情報を**「整理する」**で振り返る。
- 既知：直人は成子坂に関心／三崎は2024年に死亡／宮原は直人を最近見た／会社から情報は得られなかった。
- 未知：直人が事故を調べる理由／事故と失踪の関係／直人の居場所／黒田の知ること。
- 澪が休息を促し、湊が雨宿りに寄る流れ。

### S03-05 BAR「雨宿り」（任意）
- S03終盤で解放。**必須の事件手掛かりは置かず、訪問しなくても進行可能**。
- 怜子「いらっしゃい。……あら、湊さん」／湊「こんばんは」
- 怜子「いつもの？」／湊「ああ、頼む」
- 杏奈「佐伯さん、こんばんは」／湊「こんばんは。お疲れさま」
- 怜子は仕事の内容を深追いしない。湊が仕事から離れて過ごす場所。
- 湊・怜子・杏奈間の恋愛要素や匂わせは不要。

## 6. 制作判断ログ（**削除禁止：結論だけでなく理由を残す**）

| 論点 | 採用した方向 | 理由・避けること |
|---|---|---|
| 会社受付 | アポなしでは勤怠開示も黒田面会も不可 | 現実の企業対応を尊重。探偵に都合よく情報を出さない |
| 次の手掛かり | あかりの許可で直人の手帳を調査 | 行き詰まりから自然に行動が生まれる |
| あかりの記憶 | 「成子坂」の質問を契機に思い出す | 突然の都合のよい回想を避ける |
| 成子坂の特定 | 澪が公開情報で旧拠点を確認 | 社内秘密を偶然入手させない |
| 宮原の協力 | 名刺・事情説明・会話で徐々に信頼 | 初対面で全面協力は不自然 |
| 2024年事故 | S02では概要と現場のみ | 一度に証拠を出さず再訪に意味を作る |
| 現場調査 | 「見る」と「調べる」を使い分ける | 通常観察をすべて特別調査にしない |
| 奥村 | 警察情報を漏らさず、助言と信頼を示す | 便利な情報提供役にしない |
| 瀬川 | 警察の誇りと探偵への軽蔑、少し嫌な態度 | ただの悪役にせず正論も持たせる |
| 瀬川の成長 | 能力は徐々に認めるが親友にならない | 奥村との役割差を維持する |
| 湊の対応 | 正論を認め、挑発に乗らない | 論破や見下し合いにしない |
| BAR | 任意訪問・日常の居場所 | 重要手掛かりを必須で置かない |
| S04 | 未確定案として保存 | 仮説や会話案を決定済みと誤認させない |
| 保存方法 | 本文＋判断ログ＋未確定事項 | 箇条書き仕様だけでは創作の経緯が消える |

## 7. システム／演出ルール（引き継ぎ原記録。操作表記は上記照合注記を優先）

- Free Action：**聞く／調べる／考える／整理する／移動**（既存UIでの「見る」「話す」表現は実装仕様と照合）。
- 「見る」は通常の観察。「調べる」は必要な対象への特別な調査として使う。
- 「考える」は湊の内面であり、意味のある場面だけ。
- 「整理する」はQA形式の推理整理。証拠のない断定を正解にしない。
- 場所移動は施設内移動とMAP VIEWを区別。ビルでは1Fで階数を確認してから12Fへ。
- 伏線は自然な因果関係で出す。未取得情報を知っている前提の会話を避ける。
- 台詞はキャラクター固有の距離感・呼称を守る。
- 数字は原則半角。ストーリー上の意味がある場合だけ漢数字。
- 会話中の例文は方向性を示すドラフトであり、最終実装文言は既存設定と照合。

## 更新ルール
- 今後のストーリー議論・会話・人物設定の**編集先はこのブランチ**。単に別の草案を増やすだけでなく、採用された内容を対応する正本ファイルに統合する。
- 会話は既存台詞を確認し、残す・修正する・追加するを判断する。会話から人物像が変わったら人物設定も同期する。
- 「確定・採用」「仮採用」「提案」「未解決」を区別する。過去の記述と矛盾したら新しい採用判断を明記し、古い説明を放置しない。
- 書き込み後は**同じブランチの同じファイルを再取得して検証**する。
- `main`、ゲーム用正式原稿、アプリ実装への反映は別工程とし、無断で上書きしない。
- 旧資料は [archive/](archive/) 等に保全。過去の原会話全文が完全復元できたという意味ではない。
- 現在の5部・30シーンと会話初稿は制作基準の**仮採用案**。今後の会話検討により改訂できる。

## 会話・人物・シナリオの反復制作ループ（2026-10-26 合意）
1. 事件とシーンの目的・情報開示・人物の動機を確認する。
2. その場で自然に生まれる台詞を初稿として書く。説明のためだけの台詞を避ける。
3. 会話から人物の性格・口調・価値観・関係性を再評価し、既存設定と照合する。
4. 必要なら人物設定だけでなくシーン構成も修正し、台詞を改稿する。
5. 人物らしさ、事件の論理、情報開示、プレイヤー操作の整合を横断チェックする。
6. 採用した内容はこのブランチの対応する**マスターファイルへ反映**し、再取得して一致を確認する。

- このループは一度きりでなく、必要なだけ繰り返す。キャラクター設定は台詞を機械的に縛る固定条件ではない。
- 設定を変更するときは理由・影響する既存シーン・改稿箇所を記録する。未採用の思いつきで既決設定を上書きしない。
- 台詞の初稿、改稿、採用版を区別し、古い草案と最新版を混同しない。
- 第1部S01〜S06の既存初稿を最初の反復対象とし、その後に第2部以降へ進む。

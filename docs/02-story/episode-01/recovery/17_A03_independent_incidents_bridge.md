# A03：扉の故障と2024年の不正を分離する接続設計

作成：2026-10-24
状態：**B案の分離方針はユーザー承認済み／発見経路・会話・証拠はNEW_DRAFT（未承認）**

## 今回確定したこと

- 2026年10月の地下設備倉庫の扉故障は、直人が閉じ込められた事故の原因。
- 2024年に三崎健が気づいた架空修繕・記録の不正は**別の設備・別の出来事**。扉の故障を不正の物証としない。
- 直人は2024年の不正を知らず、失踪も黒田による監禁ではない。
- 直人は10月8日午前に救出。応答確認後は即119番通報し、調査やQAを挟まない。
- **2024年の不正と三崎の死亡事件の関係は維持**するが、佐伯が証拠を取得する経路や黒田の自白条件は未確定。

## 自然な接続の提案（NEW_DRAFT）

1. 直人を救出し、救急隊に引き継ぐ。あかりと奥村に事実を報告して、失踪の直接原因は扉の機械的な不具合として整理する。
2. 救出後、宮原に「以前から建物に不具合があったか」と確認する。宮原は地下倉庫の扉については最近の不調だと答える。**2024年の修繕偽装とは結びつけない**。
3. 会話の中で宮原が、解体前の書類整理で見つけた**別設備の古い点検控え**について言及する。「完了扱いのはずなのに、当時の点検控えでは未対応になっている」という違和感だけを示す。
4. 佐伯はそれを犯罪と断定せず、宮原に管理会社を通じて正式な照合を依頼する。無断で書類を持ち出さない。
5. 宮原は2024年に三崎も同様の食い違いを気にしていたと語る。ただし三崎の転落を目撃したわけではない。
6. 佐伯は奥村へ「直人の事故とは別に、過去の死亡事故に関係するかもしれない資料の食い違いがある」と報告。警察が必要な記録を適切な手続きで確認する。
7. その後、**資料の不一致→三崎が調べていた事実→黒田との対立**を段階的に確認。黒田の自白をこの段階で自動発生させない。

# Episode 01『消された記録』復元資料・目次（2026-10-24）

## 重要な前提

- この一式は**残存するローカルMarkdownと過去会話の記憶から回収できた情報の全体**を、出典と採用状態を混ぜずに保存したもの。元の10月23日の会話全文を一字一句照合した「完全復元」ではない。
- **PR #223/#227は操作していない**。この一式では正本として採用していない。`05` はコンテナに残る**旧アーカイブの内容を照合用に複製した歴史資料**であり、PRの採用や参照元への復帰を意味しない。
- `ACCEPTED` = 確認できる最終決定、`DRAFT` = 会話中の台詞草案、`NEW_DRAFT` = 10月24日に補完した新規創作、`HISTORICAL` = 旧時点の記録、`UNVERIFIED` = 最終承認の証拠不足、`CONFLICT` = 相互に両立しない記載。
- 台詞の最終実装承認は**未取得**。この一式をそのままゲームに自動実装しない。

# Episode 01『消された記録』――10月23日の制作感覚を取り戻すための再評価

作成：2026-10-24／**編集レビュー＋会話再設計案**。10月23日の原文逐語復元ではない。既存の台詞草案を削除・置換せず、採否は未承認。

## 1. 昨日の検討で重視した方向性（確認できるもの）

- **佐伯湊**：冷静だがドライすぎない。飄々とした軽口と人情味が共存する。相手の不安は受け止めるが、根拠のない約束はしない。
- **澪**：佐伯との日常の呼吸を作る。コーヒーと新聞、自然な応酬が導入の空気。説明役として事件の結論を先回りしない。
- **奥村**：神宮寺と熊野を思わせる旧知の関係。単なる情報提供役ではなく、互いに仕事を分かっている距離感。
- **瀬川**：警察官としてのプライドがあり、当初は探偵を警戒。単純な敵役・高圧的な悪役にせず、仕事を通じて少しずつ認める。
- **構成**：大きな展開のあとに区切り、佐伯の内面で余韻を残す。細かい場所移動だけでシーンを増やさない。プレイ時間1時間は目安。
- **ゲーム**：探偵度は調査の質の評価。低ランクでも必ずクリア可能。Free Action「聞く／調べる／考える／整理する／移動」を自然に会話と結びつける。
- **主題**：「確認した事実」と「そうだと思い込んだこと」の違い。直人は事故で閉じ込められ生存救助、黒田は失踪に無関係。2024年の三崎事件と安易に同一事件化しない。

## 2. 10/24補完稿を読み直した結果――問題点

| ID | 問題 | 現状の例・傾向 | 見直し方針 |
|---|---|---|---|
| R01 | 佐伯の台詞が事務的 | 「承知しました」「ありがとうございます」が連続し、誰が話しても同じに見える | 相手との関係に応じた軽さ・間・気遣いを入れる |
| R02 | 澪が説明・ヒント装置になりがち | 「出てきたところは、誰も確認していないんですよね」等 | 日常の自然な掛け合いから、佐伯自身の思考につなぐ |
| R03 | 奥村と瀬川の関係が平板 | 初対面の定型的な挨拶と時系列確認が中心 | 奥村の旧知の信頼、瀬川の職業的な疑いを対比させる |
| R04 | 人物が手掛かりを都合よく話す | 宮原・藤井が短い質問で核心を明かす | ためらい、誤解、記憶の曖昧さ、再確認を会話に残す |

| R06 | 2つの事件の境界が薄い | 修繕記録からすぐ黒田の自白へ飛ぶ | 直人の安否と過去の不正を別の問いとして整理 |

| R09 | EDが説明的 | 「帰ってきた。それが一番です」と主題を直に言う | 兄妹の小さな会話や澪との軽口で余韻を作る |

## 3. 書き直し例：S03 警察署（NEW_DRAFT、既存案の置換は未承認）

*廊下の向こうから、聞き覚えのある声がする。*

奥村「佐伯。お前から電話とは珍しいな」

佐伯「奥村さんに会いたくなりまして」

奥村「嘘をつけ。仕事だろ」

佐伯「ばれましたか」

奥村「何年の付き合いだと思ってる。……で、行方不明の件か」

佐伯「ええ。5日の朝に家を出て、帰っていない。成子坂のビルで姿を見た人がいます」

奥村「出たところは？」

佐伯「見た人は、まだ見つかっていません」

瀬川「『見つかっていない』だけですよね。出ていないとは限らない」

佐伯「その通りです」

瀬川「……え？」

佐伯「だから、確認したいんです。思い込みで探す場所を間違えたくない」

奥村「こいつは瀬川。まだ若いが、仕事は真面目だ」

瀬川「瀬川亮介です。探偵の方に警察の情報をお渡しできるとは限りません」

佐伯「もちろん。こちらが持っている情報を先に伝えます」

奥村「よし。見たことと、聞いたことを分けて話してくれ」

*瀬川は手帳を開く。佐伯はあかりから聞いた出発時刻、宮原の目撃、退館が未確認であることを順に説明する。*

瀬川「……失礼しました。確認できた範囲は、きちんと分けているんですね」

佐伯「疑ってもらった方が助かることもありますよ。間違っていたら困るのは、捜している人ですから」

奥村「お前も相変わらずだな」

佐伯「褒め言葉として受け取ります」

奥村「好きにしろ。ただし、危ない場所へ一人で入るな」

佐伯「そこは約束します」

**狙い**：奥村との軽口／瀬川の職務上の疑い／佐伯の事実と推測の区別を、説明ではなく会話で表す。瀬川の信頼はこの場で完全には獲得しない。**この台詞は新規草案**。

## 4. 書き直し例：ED 事務所（NEW_DRAFT、既存案の置換は未承認）

*夜。事務所の明かりがついている。佐伯が扉を開けると、澪が顔を上げる。*

澪「お帰りなさい。今日はずいぶん遅かったですね」

佐伯「少し寄り道を」

澪「その『少し』は、何時間ですか」

佐伯「……時計を見ない主義でね」

澪「都合のいい主義ですね」

*澪は小さく笑い、カップを一つ取り出す。*

澪「高瀬さんから連絡がありました。お兄さん、まだ検査は続くそうですけど、会話はできるって」

佐伯「そうか」

澪「よかったですね」

佐伯「ああ」

澪「コーヒー、淹れます？」

佐伯「頼む。いつものを」

澪「こんな時間に？」

佐伯「今日は特別だ」

澪「……では、少しだけ」

*湯の音。佐伯は窓の外に目を向ける。*

佐伯（考える）「見えていたものと、見ようとしていたものは違う。……あの兄妹には、まだ明日がある」

*カップが置かれる。*

澪「冷めないうちに、どうぞ」

佐伯「ありがとう」

**狙い**：説教的な事件総括ではなく、日常の軽口と小さな安堵で締める。事件の真相を説明し直さない。**この台詞は新規草案**。

## 5. 構成の再検討（未承認）

- S01の「新聞とコーヒー」の導入に、過去の検討で挙がった佐伯の台詞「事件が起きないなら、それが一番だろう」をどう自然に戻すか検討する。既存v2本文を勝手に書き換えない。
- S02〜S03は移動先を細かく切りすぎず、大きな調査のまとまりとして見せる。
- S04〜S09は **直人の安否確認の緊急性** を中心に再構成。倉庫の安全確認に着手できる時点で着手し、異常を知ったら救助へ。救出前に不正追及を長々と挟まない。
- S10は「黒田が自白する」結末だけでなく、そこへ至る心理・証拠・警察との役割分担を見直す。
- 探偵度は正解数や任意調査の丁寧さに影響しても、救助成功・事件解決の可否を変えない。

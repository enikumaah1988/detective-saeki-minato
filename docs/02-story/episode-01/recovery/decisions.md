# Episode 01『消された記録』決定事項（復旧ブランチ）
更新：2026-10-24。**正式原稿への反映・実装承認ではない。** 10/23原会話の逐語復元も未達。

## 作品・事件
- 現行検討タイトル『消された記録』。旧『灰色の証言』は正式原稿等に残る旧表記。
- テーマ「事実と、そう思っていることは違う」。直人失踪と三崎死亡は別件。
- 高瀬直人は2026年10月5日に成子坂共同ビル地下設備倉庫の扉故障で偶然閉じ込められ、携帯圏外。黒田による監禁ではなく、2024年の不正も知らない。
- **2026年10月8日午前**、許可・立会いを得て調査、直人の生存反応を確認したら推理を中断して即119番。夕方救出の旧構成は不採用。
- 救出後、別件の三崎事件へ。佐伯は奥村に情報を伝え、捜査権限を越えない。
- 三崎健は2024年の不正に気づき黒田を追及。黒田が衝動的に突き飛ばし、階段から転落死させた。黒田はその後、事実を隠した。
- 2024年当時は事故として扱われた。警察の無能を前提としない。

## 架空修繕・会社
- 東成ビルサービスで**複数年・複数設備の架空修繕費請求**。非常照明が発見・推理の入口。給排水・空調は不正の広がりを示す補助材料。
- 黒田の主動機は**部門売上・業績維持（B案）**。個人の金銭欲・私的取り分を主動機にしない。
- **一部役員も関与**。本編は黒田中心、役員は名前だけ。役員の捜査・処分は警察へ委ねる。
- 三崎は成子坂共同ビルの現場設備管理担当。日常点検と担当物件の修繕履歴・作業報告を確認する職務。非常照明の交換済み記録と現場の矛盾から調査し、給排水・空調の類似記録を見つけた。
- 三崎は会社を潰すためでなく記録を正そうとした。黒田は当初書類ミスとして流し、次第に圧力をかけた。
- 黒田は2024年「その日、三崎とは会っていない」と虚偽説明。2026年、勤務・入退館記録と宮原の証言を照合し説明を崩す。ただし虚偽説明と突き飛ばしの立証は別。
- エンディングでは会社に調査・改革の兆し。完全な浄化までは描かない。

## 人物・演出・進行の既決制約
- 佐伯は冷静だが人情味と軽口がある。澪は有能で自然な会話。奥村と佐伯は信頼関係があり「奥村さん」と呼ぶ。瀬川は軽い不信を持つが無能にしない。
- S01の「聞く」は「最後に会ったとき」「直人の仕事」が必須、「最近の様子」「連絡先・交友関係」「家族について」は任意。
- BAR「雨宿り」は任意。篠原怜子・小宮山杏奈と佐伯の恋愛を匂わせない。
- Free Actionは聞く／調べる／考える／整理する／移動。THINKは内面、整理はQA。推理ランクでクリアを塞がない。
- 1時間は目標であり、会話の自然さを優先。

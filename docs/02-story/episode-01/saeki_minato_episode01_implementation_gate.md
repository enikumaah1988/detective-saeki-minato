# Episode 01 実装判定ゲート（Codex向け）

## 最重要ルール

1. `saeki_minato_episode01_archive_reference_only.md` は **ARCHIVE_ONLY**。台詞・選択肢・演出の実装ソースに使用禁止。
2. 「過去に書かれた」「文書にある」「初稿に含まれる」ことは **採用の根拠にならない**。
3. 採用状態が明示されていない個々の台詞・選択肢・演出は **UNRESOLVED（実装不可）**。ユーザーの明示承認を得る。
4. 後続の案があるからといって旧案を自動で REJECTED と推定しない。**SUPERSEDED は後続合意が確認できた場合のみ**。REJECTED は明示的な不採用のみ。
5. 実装するのは **承認済みの実装用原稿** のみ。資料を混ぜ合わせて「自然に補完」しない。
6. 既存の実装に影響する差分があれば、変更前に報告する。PR #227のマージは別途承認を要する。

## 状態定義

| 状態 | 判定条件 | 実装 |
|---|---|---|
| ACCEPTED | 個別の内容について採用が明示されている | 設計基準。ただし実装範囲は別途確認 |
| DRAFT | 初稿として作成したが台詞の最終承認なし | 禁止（レビュー対象） |
| SUPERSEDED | 後続合意で置き換えられたことを確認 | 禁止、履歴のみ |
| REJECTED | ユーザーが明示的に不採用 | 禁止、履歴のみ |
| UNRESOLVED | 採否の証拠がない、または案が競合 | 禁止、確認待ち |

## 現時点の安全な判定

- **ACCEPTED（物語の大枠）**：直人の生還、2024年三崎の転落と黒田の隠蔽、二事件は無関係、S01〜S10＋EDの基本構成、救助をクイズで遅らせないこと。
- **DRAFT（実装不可）**：アーカイブに載る会話・独白・調査対象・選択肢・正解時の文言。シーンの骨格への合意は台詞の逐語承認ではない。
- **SUPERSEDED（構成順序に限る）**：S08で「扉が開かない」ことを確認した後に長い推理QAを行う旧順序。最新方針は開錠確認前に推理を整理し、異常時は救助優先。
- **UNRESOLVED**：S10黒田追及の初期短縮版と後続長文版の採用台詞、2024年の事故直後の目撃の細部、その他すべての台詞の逐語採否。
- **REJECTED**：明示的な拒否を個々の台詞について確認できていないため、ここでは割り当てない。

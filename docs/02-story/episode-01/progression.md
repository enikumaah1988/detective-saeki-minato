# Episode 01の進行と組込仕様

原稿の版の適用範囲は[話別入口](README.md)を正本とする。ここは既存の接続・取得条件・互換の整理であり、物語本文の新規改稿ではない。

- 第1部は依頼受諾だけで終えず、会社・旧ビル初訪問・帰所報告まで。第1部末の問いは、兄が過去事故の説明を求めた理由。犯人断定や兄の沈黙の理由は明かさない。
- 第1部の帰所報告でF39・F40・IT04を取得し、警察の確認E02・F36・F41は第2部へ残す。黒田の説明は本人からの未確認の伝聞と区別し、鍵の空欄から返却時刻を断定しない。
- 第2部は事務所14:30の警察連絡→署前14:45→受付14:50→面会14:55→退出15:15→帰所15:35→整理15:40→直人の折返し15:50。第3部16:10開始・16:30面会、第4部の日時・本文を維持する。
- P1-03は基本3問→勤務先／捜索状況と回答に応じた追加→普段の兄／相談内容の確認。依頼後半は進め方／範囲→写真／連絡先→帰ってきたら／お見送り。任意話題を持ち越して後半を膨らませない。
- 主な聞き取りの区切りはP1-03「相談内容の確認」、P3-04「証言の確認」、P3-06「書類についての確認」、P4-07「説明の確認」。必要情報を読了してから表示し、その間は元の一覧で任意会話を選べる。
- topicTransitionsは条件成立した会話の読了後に一度だけ挟む。conditionalNextを場面終了のnextWhenより先に評価し、つなぎの読了後は元の相手の話題一覧へ戻る。仕様上限8件と既存検証の観測最大7件を区別する。
- 第3部W01は顔の目撃と訂正意思、第4部W02は押す動作、I05は位置照合。正解・証言範囲・未取得情報を先取りしない。推理は第2部・第4部の既存位置を維持する。
- 導入4段落→共通仮扉絵→日常へ接続する。部間全8箇所は共通の仮扉絵。C1-OUTは帰所報告末、C2-INは警察連絡開始。旧7場面絵を完成扉絵として復活させない。完成キービジュアルは別途イメージ整理待ち。
- 表示は年なし、内部は2026年・過去事件2024年。時計の節目は既存取得情報から復元し、再訪で逆行させない。

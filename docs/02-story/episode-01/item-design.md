# Episode 01 アイテム設定・入手と使用の設計

状態：**設計方針合意・個別アイテム未確定**（2026-11-03、PR #274）。本書は事件・シーンでのアイテムの**取得、所持、利用、情報開示**を一元管理するための資料。作画素材の正本、ゲーム実装・既存UIの変更指示ではない。

## 目的・参照関係

- Episode 01で**湊がストーリー中に手に入れる物品**を、証拠品だけに限定せず扱う。最初から所持する物、調べるが持ち帰らない物、資料として得る情報も対象。
- 物語とシーン進行の整合は[事件固有設定](episode-setting.md)と同書のN01〜N30再構成設計を参照。人物の共通属性は[人物設定](../../03-characters/人物設定.md)、建物の物語設定は既存の[ロケーション設定](第1話_ロケーション設定.md)や[東成ビルサービス](東成ビルサービス.md)を優先する。
- **操作・持ち物の現行仕様**は[actions.md](../../01-game-design/actions.md)を優先。調査対象の「見る」と「調べる」は異なり、単に存在を見ただけでは所持・取得としない。資料の使用先・話題解放・セーブ復帰は既存の条件管理に従う。新UI・アイテム欄追加は**未決定**。
- アイテムの**見た目・制作条件・画像採用**は[04-art/items](../../04-art/items/README.md)へ。そこに既存のスマホ・電子タバコ・名刺の素材案がある。制作済み画像がゲーム中で使用・採用済みであるとはみなさない。ゲーム画像実体の置き場所は`src/assets/images/items/`。

## 区分（重複を許容）

| 種別 | 例 | 主に追跡すること |
| --- | --- | --- |
| 所持アイテム | 初期持ち物、他者から預かる鍵・メモ・物品など | 初期状態、入手シーン、使用先、返却・消費、以後の保有 |
| 調査対象アイテム | 現地の図面・設備記録・室内物品 | 発見・閲覧条件、調査で分かる事実、閲覧権限、持出可否 |
| 証拠・情報アイテム | 報告書、社内連絡の存在、屋上のボタンに関する情報 | 誰が保管し、誰が何を知るか、開示時点、証明できる範囲 |

**区分と取得状態は別軸。** 「湊が内容を知っている」「湊が現物を持っている」「写しを持っている」「プレイヤーが操作できる」を混同しない。見せるだけ・調べるだけの対象が自動的に所持品へ増えるとはしない。

## 1件ごとの登録項目

| フィールド | 記録内容 |
| --- | --- |
| ID／表示名 | 一意な仮ID・名称。実装IDの採用は別途照合 |
| 種別 | 所持／調査／証拠情報（複数可） |
| 設定上の存在・保管者 | 所有者、原本・現物の所在、合法的なアクセス経路 |
| 初期状態 | 初期所持／未発見／閲覧可能／情報のみ等 |
| 発見・取得シーンと条件 | どこで、誰から、何をして取得するか |
| 湊の取得状態 | 現物／写し／閲覧のみ／内容の伝聞・記憶 |
| プレイヤーができる操作 | 見る・調べる・示す・話題解放・整理する等、現行仕様との対応 |
| 使用先・役割・終了条件 | 利用シーン、対象人物、推理で示せること・示せないこと |
| 消費・返却・持出制限 | 消費品か、返却するか、事件後どう扱うか |
| 開示・採用状態／根拠 | 作者合意・委任設計・未決を区別し出典を添える |

## 具体的な対象の棚卸し（個別仕様は未採用）

| 対象 | 現時点で守るべき制約 | 今後決めること |
| --- | --- | --- |
| 湊のスマホ・電子タバコ・名刺 | 04-art/itemsに制作済みの**素材案**あり。既存の持ち物定義と照合する | 初期所持・表示・使用範囲を現行データと確認 |
| 直人の直近業務報告書 | 自宅等で**許可された範囲で内容を確認**。三崎事件の旧資料ではない | 現物持出しの有無、写しの取得条件、調査記録への記載 |
| 現場の新旧図面・作業記録 | 湊の現場調査・旧保管室発見に必要だが、自由持出しを前提としない | 閲覧方法、操作対象、整理する際の利用条件 |
| 修繕履歴と協力会社依頼記録 | 藤井が社内権限内で確認。湊は説明を受ける | プレイヤーに提示する要約表現、個別資料の取得状態 |
| 三崎の報告書・受領署名 | 村瀬が旧システムで確認、湊へは**存在・内容の説明が中心**。署名原本・画像は渡さない | 情報アイテム化と閲覧表現、証明範囲 |
| 屋上呼出しメール・保存PDF | 元メールとPDFが同一内容なら**独立物証として二重計上しない**。湊は全文を自由に保有しない | 調査記録への要約表示、警察による正式確認との接続 |
| 屋上で発見されたボタン | **警察の保管物**。湊・黒田に発見位置、採取写真、現物を告白前に見せない | 「存在を知った」という情報の扱い、後日の照合描写 |

## 未決事項と禁止する先取り

- ゲームにアイテム欄を新設するか、既存の持ち物・調査記録機能で表現するかは未決。まず現行UI・`src/data/investigation.ts`等の挙動を確認する。
- 上表の候補をすべて**湊が所持するアイテム**として採用しない。入手・閲覧・情報の区別、使用先の有無をシーン単位で検討してから正式決定する。
- 消費・返却・合成や専用ミニゲーム等の新機構を、アイテム資料を作ることだけで確定しない。
- 警察保管物・企業の秘密資料の自由な持出し、未取得情報の先読み、同じ記録の二重証明を避ける。
- 採用済みの事件真相・キャラ設定を変更せず、具体的なアイテム一覧・取得条件の決定は次の設計工程とする。

以下は**既存のストーリーと操作条件から導ける範囲のみ**記録したシーン対応表。新しい持ち物の付与・取得方法は決定せず、取得状態を仮に区別。分類名は管理用で**ゲーム内表示の採用ではない**。

| 仮ID | 対象 | 初出／利用場面 | 湊の取得状態 | 推理・ゲーム上の機能／留意点 |
| --- | --- | --- | --- | --- |
| INV-01 | 依頼人からの聞き込み情報 | N01→N02 | 情報のみ | 最後の接触・勤務先、他2項目任意。手動終了を妨げない |
| INV-02 | 直人の勤務予定・担当施設情報 | N03→N05 | 情報のみ／資料の閲覧条件未確定 | 実勤務と最後の足取りを整理。会社の内部文書を自動取得しない |
| INV-03 | 直人の直近業務報告書 | N04、N12 | **閲覧した内容は把握**／現物・写しの所持は未決 | 救出後に再発と修繕完了の不一致を再検討。2024年事件の資料ではない |
| INV-04 | 新旧施設図面・作業記録 | N05〜N09 | 管理者の許可の範囲で閲覧／現物所持未決 | 廊下の長さと室配置の差を組み合わせ、湊が旧保管室を推理 |
| INV-05 | 藤井が照合する修繕履歴・協力会社依頼 | N13〜N16 | 藤井から**概要・存在の説明** | 同種案件と三崎の異議へ。会社の記録そのものを湊の所持品にしない |
| INV-06 | 三崎の技術報告書・受領署名 | N20〜N24 | 村瀬・藤井から**存在・内容の説明**／原本未所持 | 黒田が報告書を受領した事実と屋上面会を区別する。署名原本の真正性は警察が独立確認 |
| INV-07 | 屋上呼出しメール・保存PDF | N20〜N26 | **存在・内容の説明**／元メール全文・PDF原本未所持 | 黒田が呼び出した疑い。元メールとその保存PDFを別々の独立証拠にしない |
| INV-08 | 2024年屋上のボタン | N22、N29 | **存在を知るだけ**／警察が現物保管 | 位置・写真・型・詳細を非公開にし、告白後の警察の照合に使用 |

**本時点でストーリー中に湊が現物を新規入手すると確定した物品はない。** 「取得可能アイテムはゼロ」と断定するのではなく、今後のシーン台本で持ち帰り・提示・返却の導線を設計するため**未確定**とする。警察保管ボタン、会社の原本は取得不可の境界を維持する。


## 取得・使用・提示のシーン別設計（委任提案・レビュー待ち）

**作業範囲：** すでに決まった事件進行をゲーム資料へ落とす。ゲーム中に湊が新しく「現物を受け取った」とはまだ確定していないため、下表は**操作候補**であり新規所持の採用を意味しない。

| 仮ID | 発見・入手時点 | 仮のゲーム内状態 | 使用・提示・整理 | 主なゲート／制約 |
| --- | --- | --- | --- | --- |
| INV-01 聞き込み | N01 | 取得済み情報（必須2、任意2） | N02で整理 | 必須取得後も手動終了。任意2を未取得でも進行可能 |
| INV-02 勤務予定 | N03 | 調査記録（本人の最終行動に関する概要） | N04〜N05で照合 | 勤務先が開示できる範囲の情報のみ |
| INV-03 直近報告書 | N04 | **閲覧済み・要点を記憶**。コピー所持は提案待ち | N12で思い返し、N14で代替仮説 | 再発の記録は不正の確証ではない |
| INV-04 施設新旧図面 | N05〜N08 | 管理者の許可の下で閲覧／照合した情報 | N06は違和感、N08で空間推理 | 図面原本・建物の鍵を湊に自動交付しない |
| INV-05 修繕・発注記録 | N13〜N16 | 藤井から聞く情報／要約 | N15の類似案件、N16の三崎の異議に接続 | 社内から無許可のコピー持ち出しをさせない |
| INV-06 三崎報告書・署名 | N20〜N24 | 原本の所在・内容についての**情報** | N24、N26で受領と屋上対話の違いを検討 | 署名原本・画像を湊が保有する演出は不可 |
| INV-07 屋上呼出メール | N23〜N26 | 発信事実・要約の**情報** | N26の推理①に関係 | メールがあること≠実際に会ったこと。PDFとの重複に注意 |

### ストーリー中に湊が手に入れるアイテムの設計枠

現時点で**現物入手が確定した新規アイテムはない**。この空白を埋めるため、次の候補は作者レビュー前の設計素材として扱い、ゲーム進行を必須依存させない。

| 候補 | 想定場面 | 入手の前提 | 利用の可能性 | 状態 |
| --- | --- | --- | --- | --- |
| 調査用の手書きメモ | N01〜N02 | 湊が自分で記録する | N02の整理で見る | **提案・新規取得未決** |
| 担当施設・作業予定の控え | N03 | 勤務先が任意に開示・交付した範囲 | N05で作業区画を照合 | **提案・交付権限未検証** |
| 施設図面の許可済み写し | N07〜N08 | 管理者による複写許可 | 現場の旧区画推理 | **提案・必須としない** |
| 協力会社名のメモ | N13〜N15 | 藤井の説明を湊がメモする | 社外の公開情報を当たる手掛かり | **提案・捜査資料の持ち出しではない** |

### 台本化前の確認条件

- 新規アイテムは**最低1つ意味のある再使用先**がある場合に採用を検討し、単なるリスト埋めの収集物にしない。
- 「手掛かりとして記録する」と「実際の所持品欄に追加する」は別の仕様判断。既存`src/data/investigation.ts`の分類・状態・SaveData version 2との互換を実装段階で点検する。
- 各シーンで取得・閲覧・使用を明文化しても、会話や推理の**既存の必須条件**が無断変更されるわけではない。
- 警察保管ボタン、黒田宛の原本、会社の内部メールの全文は、湊の収集アイテムにしない。

# E01-S08「図面の照合」シナリオ・推理問題草稿 v0.3（論理座標・画面検証契約）

> **状態：全文・図面配置・回答候補・正誤・補助・遷移とも未採用（2026-11-06）。** S08の「推理する」通常調査からの手動開始、推理画面内「考える」、回答候補選択→明示確定、正解後S09への連続接続という基本操作契約は[actions.md](../../../01-game-design/actions.md)に従う。作者承認済みの旧倉庫の事件設定を変更しない。**下記の具体配置は作画前の仮配置**であり、構造・寸法・視認性を検証するまでは公平性の合格判断をしない。旧30シーンの実装対象ではない。

## 目的・演出上の到達点

- 場所：成子坂共同ビル管理室（必要に応じ廊下の観察カットを挿入）。湊と澪。宮原は管理者・安全確認窓口として近くにいる。
- **既知情報：** S05で現行管理図面INV-04／台帳INV-05、S06で現場通路の突き当たり・壁位置と設備室列の不一致INV-06、S07で旧図面と改修履歴INV-07。
- **問いの証明範囲：** 「管理者に**最初に確認を依頼すべき旧分岐の入口候補位置**」を一か所に絞るだけ。旧倉庫が今も完全に残る、直人がそこにいる、無断立入りできる、とは確定しない。

## 推理用の空間関係・図面仕様 v0.2（描画・実装前の未採用仮配置）

**この章の三図は位置関係を同じ向きに整理した「論理検証用模式図」であり、実在建物の建築図面・縮尺図ではない。** 図面の原本が湊の所持品になるという設定ではなく、宮原が閲覧を許可した情報をS08画面で図式化して再参照する演出案。

### 1. 比較条件と座標の意味

- 視点を統一する。**上＝北／通路奥、下＝南／管理通路入口、左＝西、右＝東**。
- 変わらない基準は南側入口、通路東側の**設備室A扉→設備室B扉の順番と位置**。この2扉の相対位置はS05〜S07の全情報で一致する。
- 下記の行番号 `R0〜R6` は**位置の上下関係だけ**を示す図面設計用仮ラベル。メートル数・寸法・建築上の壁厚・測量精度を示さない。ゲーム画面には行番号を出さず、**扉A・Bと通路端、旧分岐の輪郭**が読み取れる表示を優先する。
- 重要な差：**現行管理図面での通路端はR1付近**に描かれているが、**S06で見た現場の正面突き当たりはそれより入口寄りのR2付近**。突き当たりの西側に設備・間仕切りがあり、横方向を見通しにくい。この差はS06の観察で明示する。縮尺の見かけだけを証拠にしない。
- **改修前図面では設備室Bの奥（R2〜R1付近）の西側へ短い枝通路が分かれ、旧倉庫に続く。** 改修履歴はこの奥側の間仕切り・設備配置が変更されたことを示すが、隠れた現在の開口部位置や旧室の存続を確定しない。
- 建築・避難安全上、**旧枝通路の入口は完全に塞がれていない**という正本の前提を保持する。正面の突き当たり壁と西側の曲がり込んだ通路は別。通常動線では設備の陰に入り、入口が直視できない。S09で管理側が現地確認して初めて通路の接続を確認する。

### 2. 3資料の同一方角の模式表示

**図① 旧図面（S07で閲覧）**

```text
R0   [旧倉庫] ←──旧枝通路
R1                 └─┐ 旧分岐（西側）
R2                   │
R3                   │    [設備室B 扉]
R4                   │    [設備室A 扉]
R5                   │
R6                [南入口]
```

**図② 現行管理図面（S05で閲覧）**

```text
                 北 ↑       西 ←       東 →
R0              （記載なし）
R1                   ┏━━ 正面の通路端（図面上）
R2                   │    （奥の設備配置は簡略）
R3                   │    [設備室B 扉]
R4                   │    [設備室A 扉]
R5                   │
R6                [南入口]
          ※旧枝通路・旧倉庫は記載されない
```

**図③ 実際の通路（S06で目視）**

```text
                 北 ↑       西 ←       東 →
R0             （視界に入らない）
R1             （見通せない）
R2        [設備の陰] ▣━━ 正面の突き当たり壁（実景）
R3                   │    [設備室B 扉]
R4                   │    [設備室A 扉]
R5                   │
R6                [南入口]
          ※西の設備陰の先に開口が「ある」とは見えていない
```

**表示条件：** 図①〜③の設備室A/Bは、すべて**同じ位置と順序**で描く。比較対象を切り替えても入口・扉・上下左右が動いて見えない。現行図面と現場の正面端は、見比べれば前後差が分かる描写にする。図①の「旧倉庫」の部屋表示自体は公開済み情報であり、現在の入口や救出対象の位置を指すマーカーにしない。図③の設備陰に「扉」「隠し通路」などの解答表示は付けない。

### 2-A. 作画・画面表示の共通座標契約（v0.3・未採用）

三図を別々の絵として描くのではなく、**同じ基準点から登録した位置情報を、資料ごとに重ねて表示**する。以下の座標は比較・UI確認専用の**無次元の論理グリッド**であり、建築寸法、通路幅、壁厚、位置測量や安全確認を表さない。

| 基準・物体 | 論理座標（列, 行） | 旧図面 | 現行図面 | 現場観察 |
| --- | --- | --- | --- | --- |
| 南入口・原点 | (中央, R6) | 同一 | 同一 | 同一 |
| 設備室A扉 | (東, R4) | 同一 | 同一 | 同一 |
| 設備室B扉 | (東, R3) | 同一 | 同一 | 同一 |
| 旧西側分岐の存在範囲 | (西, R2〜R1) | **描く** | **描かない** | **見えていない** |
| 現行管理図面の正面終端 | (中央, R1) | 未適用 | **描く** | 未適用 |
| 現場で見える正面壁 | (中央〜西寄り, R2) | 未適用 | 未適用 | **描く** |
| 現場で見える設備・間仕切りの陰 | (西, R2) | 未適用 | 未適用 | **描く** |

**方角・相対配置の不変条件：** 全資料で北上、入口下、AはBより南、A/Bは東側、旧分岐はBより北かつ西側。現場の正面終端と図面上の終端が違っても、**縮尺差・壁厚・改修**の影響は排除できない。現場観察では設備陰の先の入口や通路を描かない。

**候補表示の論理アンカー：** A=(西,R5)、B=(西,R2)、C=(東,R4)。候補マーカーは現場観察レイヤーに同時表示。仮ラベルA/B/Cの位置は**回答操作を通じて固定**し、資料切替で飛ばさない。正解Bと旧分岐を同じ色にしたり、Bにだけ特別な枠・アニメーション・矢印を付けたりしない。

**画面構成の暫定仕様：** 「現場図③」を中心にA/B/Cの地点を選択し、同じ向き・画面枠の「旧図面①」「現行管理図面②」を切替または重ね合わせて照合する。重ね合わせを採る場合、南入口と設備室A/B扉を常に固定アンカーにし、回転・鏡像反転・拡大で候補位置をずらさない。図面の文字は縮小表示でも読み取れる設計とする。紙図面を物理所持した扱いにはしない。

**検証用の比較表（プレイヤーが既知の情報だけ）：**

| 候補 | B扉より北側か | 通路の西側か | 改修された奥側か | 採否 |
| --- | --- | --- | --- | --- |
| A（西,R5） | いいえ | はい | いいえ | 不一致 |
| B（西,R2） | はい | はい | はい | **優先確認位置** |
| C（東,R4） | いいえ | いいえ | いいえ | 不一致 |

**必要な制作・受入テスト（未実施）：** (1) 三資料を同一フレームの状態別画面として制作、(2) A/B扉と入口の座標ズレがないことを画像で検査、(3) Bが旧分岐に重なる一方で**見えない入口そのものを描かない**、(4) A/Cを選んだ場合の誤答説明が絵と一致、(5) 初見の第三者にヒントなしで位置を選ばせ、縮尺・壁厚・全撤去の反例にも納得できるか確認、(6) B正解後・誤答後・LOAD後の進行を実機で検証。**現段階でこれらのテストを実施済みとはしない。**

### 3. 回答用の現場位置候補

位置マーカーは**現場図③**に同時表示する。全候補は「管理者に調べてもらう場所」という同じ粒度とし、画面上に正解色・旧倉庫アイコンを付けない。

| 仮ID | 仮の表示名 | 図③に置く位置 | 他の資料と比べる観点 |
| --- | --- | --- | --- |
| A | 入口近くの西側壁 | R5の西側 | 旧図面の分岐より設備室A/Bの**手前** |
| B | 奥の西側、設備の陰と間仕切り付近 | R2の西側（設備室B扉より北側） | 旧図面の**B扉より奥・西側分岐**と対応し、改修範囲にも重なる |
| C | 設備室A扉の東側 | R4の東側 | 旧図面では通常稼働設備室Aの扉があり、旧分岐の**反対側** |

**Bだけが旧図面の「設備室Bより奥・西側」という二重の位置条件と、改修範囲の条件に整合する。** ただしこれは「その付近を確認することが最も合理的」という仮結論であり、通路や旧倉庫が現在も残ることを論証しない。S09で管理側が設備配置の奥を現地確認し、初めて開口へ進めるかを判断する。

### 4. 反例チェック：他の説明は何を否定し、何を否定しないか

| 反例 | この時点での評価 | 推理の論理への影響 |
| --- | --- | --- |
| 「図面の縮尺が違うだけ」 | 尺度不一致で**通路端の見かけの差**は説明し得る | 入口・A/B扉という共通位置基準と**西側分岐の相対位置**までは消さない。ただし現場差の証拠力は弱まる |
| 「間仕切りや壁厚の影響」 | 正面壁の前後差は説明できる | **B付近に探索対象がある可能性**を否定しないが、隠れた入口が実在するとまでは言えない |
| 「旧枝通路は改修で完全撤去された」 | 旧図面と現場だけでは排除できない | Bを**優先確認位置**にすることと両立。S09で初めて存否を確かめる |
| 「入口A/Cにも別の見えない空間がある」 | 未知の別空間の可能性は一般論として残る | **今回の旧倉庫につながる旧分岐**という問いに対し、旧図面と場所が合わないため候補にならない |

推理問題は**正解Bを選んだから今も旧倉庫が存在すると証明できた**という構造にしない。現場差だけでも、旧図面だけでも不十分。少なくともS05の基準扉位置、S06の壁・設備観察、S07の旧分岐・改修範囲を照合する必要がある。

**佐伯 湊**

「ああ。だが、今も通れるとは限らない。」

**相澤 澪**

「図面の縮尺が違うだけ、ということはありませんか？」

**佐伯 湊**

「それも考えたい。どの位置が一致していて、どこから食い違うのか……。」

【演出】湊はS06で観察した設備室の並びと突き当たりを思い返す。

**佐伯 湊（内心）**

「現場を確かめてもらうなら、候補は絞っておきたい。」

【処理】**推理対象「旧分岐の確認位置」認識済み**を設定。通常調査に「推理する」を表示する（未取得情報があっても、この時点から外観を変えず表示する）。「推理可能！」などの正解タイミング通知は出さない。

## 「推理する」入口（手動／未採用）

**情報不足時の反応：**

**佐伯 湊（内心）**

「今ある情報だけじゃ、場所を絞れないな。現場で見た位置と、図面の違いを確認しよう。」

【処理】短い独白後に通常調査へ復帰し、誤答扱いはしない。図面・観察が揃っても表示色や文言を変更せず、同じ入口で問題へ進む。

**情報充足時の中立的な問い：**

**佐伯 湊（内心）**

「改修前の分岐を今の配置に当てはめるなら、管理者にどこを確認してもらうべきだろう。」

## 回答候補（新規・未採用。図面上の3か所を表示する位置推理）

| 仮候補ID | 画面上の位置表示 | 正誤 | 選択理由・検証条件 |
| --- | --- | --- | --- |
| A | 入口近くの西側壁（R5） | 誤答 | 共通基準の設備室A/Bより手前で、旧図面の分岐位置と合わない |
| B | 設備室Bの扉より奥、西側の設備陰・間仕切り付近（R2） | **仮正解** | 旧図面の枝通路の分岐位置と設備室Bの位置関係が合い、現場の見通しが変わった区域に重なる |
| C | 設備室A扉の東側（R4） | 誤答 | 稼働設備室Aの出入口と重なり、旧図面の西側分岐に対応しない |

**回答操作：** 地点を一つ選択し、別の「回答を確定」で判定。選択しただけでは進行しない。調査記録や「考える」から戻っても未確定選択とフォーカスを維持（LOADをまたぐ復元は約束しない）。候補を情報の取得状況に応じて色分け・削除しない。**設計図の絵がA/B/Cの説明と一致しない限り、この正誤は仮置き**。

### 誤答A

**佐伯 湊（内心）**

「そこは旧図面でも、設備室より入口側だ。分岐の位置とは合わない。」

【処理】同じ問題へ戻る。選択を解除。ペナルティ、ヒント自動開示、正解候補削除なし。

### 誤答C

**佐伯 湊（内心）**

「ここは今も使っている設備室の側だ。旧図面の分岐は、その反対側だったはずだ。」

【処理】同上。選んだ根拠の不足だけを説明して正解位置を指差さない。

## 推理画面内「考える」任意補助（未採用）

通常調査の常設「考える」は増やさず、推理画面でのみ表示。押すごとに**本人の内心を既存の台詞ウィンドウ**で1段階表示し、読了後同じ問題へ戻る。1段階目の後は同じ位置のラベルを「もう少し考える」にし、最終段階後は消す。開示した内容は通常LOGへ初回一度だけ記録。誤答回数・経過時間で自動強化しない。

- **段階① 着眼点：** 佐伯湊（内心）「図面の違いを探す前に、変わっていないところを押さえよう。」
- **段階② 比較対象：** 佐伯湊（内心）「設備室の並びは同じだ。そこを目印にすれば、新旧の通路を比べられる。」
- **段階③ 判断方法：** 佐伯湊（内心）「旧図面の分岐と、現場で配置が変わった範囲を、同じ目印からたどってみるか。」

補助だけで新たな図面・壁の情報を付与せず、選択肢ID・候補名・最終回答を明かさない。段階③が事実上の正解提示にならないかレビュー対象。

## 仮正解B → 結果会話 → S09（未採用）

【演出】湊が図面上の一か所を示す。ここでは壁を叩いたり破壊したりしない。

**佐伯 湊**

「設備室の位置は変わっていない。昔の分岐は、その奥の西側にあったはずだ。」

**相澤 澪**

「間仕切りが変わった場所と重なりますね。でも、今もそこが通れるかどうかは……。」

**佐伯 湊**

「分からない。だから、管理者に確認してもらおう。」

【演出】湊が宮原に候補位置を説明する。

**宮原 文雄**

「分かりました。ここは管理側で安全を確認します。必要なら専門の方にも来てもらいます。」

**佐伯 湊**

「お願いします。中の様子が分からない以上、無理はできません。」

【処理】推理の**回答成立**と、**結果会話読了によるS09連続イベント開始**を別段階として扱う。ここでは直人の居場所・生存確定は付与しない。プレイヤーが結果会話から任意調査へ戻り、再度同じ推理を解くループは作らない。S09で実地確認・反応・救助担当への連絡につなげる。

## 情報・保存・入力契約案（未採用）

| 仮状態 | 確定条件 | 扱い |
| --- | --- | --- |
| S08_TARGET_RECOGNIZED | 導入の比較対象を認識 | 通常調査の「推理する」入口を表示 |
| S08_EVIDENCE_READY | 現行図面・台帳・現場観察・旧図面・改修履歴の必要情報 | 入口から問い／3候補へ入れる。既読任意会話は不要 |
| S08_POSITION_ANSWERED | 選択Bを「回答を確定」して判定成立 | 正解回答済み。結果会話の未読先頭へ原子的に移動 |
| S08_CONFIRMATION_REQUESTED | 宮原へ確認を依頼する結果会話を読了 | 管理側確認のS09へ連続接続。直人の生存はまだ未確認 |

- 未選択の確定は入力不能（誤答ではない）。誤答は非進行で同じ問いに復帰。LOG/記録閲覧・補助で回答を勝手に確定しない。
- SAVE/LOADは既存flagsと安全なnodeIdで復帰。回答済みで未読結果会話がある場合、問いを再要求せず未読台詞から続行する。回答選択中の一時カーソルは保存必須にしない。原子的な確定途中でSAVEを受け付けない。
- S08は管理室等での推理のため、**喫煙による攻略補助なし**。追加の通常調査「考える」コマンドもなし。
- **重要：** R0〜R6の論理座標は物理寸法を未決とするため、今回指定した共通グリッドに従う三状態の画面を実際に作画し、通路端・設備室A/B扉・候補マーカーの位置を固定して検証する。建築図面・通路奥行き・避難動線の成立は未検証。固定基準の図面描写が実際の作画で同じ視点・位置関係を表現できない場合、候補・正誤を再設計し、S08はレビュー未合格とする。

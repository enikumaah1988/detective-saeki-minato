- **今回の開示：** 藤井が自分の担当範囲内で確認した案件の**概要**。**管理側への完了報告と会社側の案件が対応し、同じ設備に後続の類似不調記載があると藤井が確認した**こと、会社側の記録に完了処理があること、その後の類似不調記載があること、同じ協力会社が別案件にも現れること、以前も似た異議があったらしいこと。あくまで**藤井が確認できた概要の伝聞**であり会社原本の手渡しではない。
- **まだ開示しない：** 正確な修繕金額・請求書、顧問料還流、役員の甥との関係、三崎の名前と死亡、2024年負傷事故の詳細、黒田の意図的な虚偽承認。協力会社の架空の固有社名・個別担当者のプロフィールをここでは確定しない。
- **証拠の種類：** 藤井の業務上の確認結果から聞いた**限定的な説明**。湊は帳票原本・内部システムの画面・PDFを持ち帰らない。藤井の職務上の閲覧と社外説明の権限を分け、個別照合結果を外部に話すには所管窓口等の適切な根拠が必要。**C層の事前確認が成立する場合のみ以下の個別結果を語る未採用案**とする。

## 藤井の閲覧権限と社外説明の条件（v0.5・未採用の優先案）

**優先案：非関与の所管窓口が、社外への説明可能範囲を限定して回答した後にS14の面談を行う。** 藤井本人の裁量や「口頭だけだから問題ない」という理屈で個別情報を漏らさない。窓口の担当者・役職・社内規程・確認方法は**未設定の制作上の提案**であり、会社が実際に承認したという正本上の事実にはしない。

- **A：湊が既に把握した情報と一般的な照合手順** — S04私的メモ、S05管理側の完了報告の閲覧内容を受け、藤井は一般的な設備・案件照合方法を自由に説明する。この段階では会社の新情報を開示しない。
- **B：藤井による社内確認** — 担当業務の権限内で、設置区画、設備管理上の識別、完了報告に対応する社内案件、後続の異音記録、協力会社との関係を確認する。**調べられることは開示許可ではない**。
- **C：社外への限定説明** — 藤井が非関与の所管窓口に、*外部者の問い合わせに回答可能な項目*を確認する。**許可がある場合のみ**「該当設備に会社の完了処理がある」「同じ設備に後続の類似不調記載がある」「同一協力会社がほかの案件にも関係する」という**非特定化した概要**を話す。設備ID、案件番号、会社名、金額、個別社員、原本や画面は示さない。社外秘情報の概要なら当然許されるという扱いにもしない。

**成立条件と分岐の扱い：** この草稿はCの限定説明が可能との確認を得た場合の台本であり、**確認が取れない場合は同じ台詞を発話させない**。その場合の代替はAの手順説明と「社内の記録については、正規の窓口で確認してほしい」という回答にとどめ、個別の会社側確認結果は後続の正式経路（S17〜S19の社内調査・所管窓口・警察による取得）へ繰り延べる。ゲーム内の任意の権限取得パズルや分岐シーンを新設する意図はない。**正規の確認が成立したという制作上の事実の作者承認と、守秘・権限の妥当性チェックを受入条件に残す**。

**他場面との区別：** S14で仮に許可されるのは設備・修繕対応に関する*限定的概要*まで。S17の三崎報告書・署名・私信メールのアーカイブ調査は別の資料であり、S19での外部説明について**新たな個別の許可・正式取得経路が必要**。S14の確認をS17〜S19の包括的な開示権限に流用しない。S15の三崎に関する藤井の記憶・本人が経験したことと、社内資料の開示も混同しない。

# E01-S10「直人の救出」シナリオ台本 — レビュー前草稿 v0.1

> **状態：全文未採用・未実装（2026-11-06）。** [事件設定](episode-setting.md)の約60時間後の救出・医療描写の曖昧化を維持し、未検証の扉機構や具体治療を作らない。S09からの連続イベント。既存30シーンの実装は変更しない。

## シーン契約

- **場所：** 成子坂共同ビル地下旧設備倉庫の近傍。登場：湊、建物側担当、宮原、消防等の救助担当、救急担当。直人は救出後に確認される。
- **前提：** S09で扉付近から弱い応答が確認され、専門担当による開放が準備されている。
- **到達点：** 建物側・消防等が安全確認した上で開放し、ひどく衰弱した直人を発見・本人確認・搬送。湊は位置推定と情報連絡の役割。救助は専門担当が行う。
- **禁止：** 湊が扉をこじ開ける／医療行為する。扉を防火扉・避難用非常扉に確定。医学的な診断・点滴・脱水の程度・治療日数を台詞で決める。直人が今ここで2024年の犯罪・不正を語る。

## 開放から発見（新規・未採用）

【演出】

管理側と救助担当が扉周囲と設備の安全を確認し、必要な対応を進める。湊は通路の安全な位置で待つ。作業の具体的方法は映さず、音と待機の間で時間の経過を表す。

**救助担当（役名仮）**

「……開きます。中を確認します。」

【演出】

扉が開く。救助担当が奥へ声をかける。少し離れた位置にいた湊は、担当者の表情が変わるのを見て息を止める。

**救助担当（役名仮）**

「人がいます。救急の対応をお願いします。」

**宮原 文雄**

「高瀬さんでしょうか。」

**佐伯 湊**

「確認をお願いします。」

【演出】

安全が確保された範囲で、救助担当が身元の確認を進める。直人は床近くに身を寄せており、長い会話はできない。

**救助担当（役名仮）**

「高瀬直人さんで間違いありません。搬送の準備をします。」

【演出】

湊は立ち入らず、担当者の声を聞いてようやく息を吐く。

**佐伯 湊（内心）**

「……見つかった。」

【処理案】

`S10_NAOTO_FOUND`（直人発見・本人確認）を確定。S08の推理正解を「直人の所在を最初から知っていた」と書き換えない。

## 救急搬送・あかりへの連絡（新規・未採用）

【演出】

救急担当が直人の状態を確認し、搬送の準備を進める。診断名・数値・具体処置は描写しない。

**救急担当（役名仮）**

「病院で確認が必要です。搬送します。」

**佐伯 湊**

「お願いします。」

【演出】

湊は通路を離れ、邪魔にならない場所からあかりへ連絡する。

**高瀬 あかり（電話）**

「……佐伯さん？」

**佐伯 湊**

「高瀬さん。お兄さんが見つかりました。」

**高瀬 あかり（電話）**

「……兄が？　本当ですか？」

**佐伯 湊**

「はい。今、病院へ向かうところです。詳しい状態は、まだ確認中です。」

【演出】

電話の向こうで、あかりが息を呑む。

**高瀬 あかり（電話）**

「……生きて、いるんですよね？」

**佐伯 湊**

「ええ。救助されています。病院で確認が済むまで、落ち着いて連絡を待ってください。」

**高瀬 あかり（電話）**

「……分かりました。ありがとうございます……。」

【演出】

湊は電話を切り、搬送に向けて動く人たちを振り返る。

【処理案】

`S10_AKARI_NOTIFIED`（発見・搬送状況の連絡）を確定。救出時点の健康状態を「もう安心」「完治した」とは断定しない。搬送先・来院方法の具体的な案内は実務整合を確認して追加可能。

## 直人の短い発話（採否保留・新規未採用）

【狙い】

**長い説明をさせない**という作者既決条件を守るため、救出直後は直人に説明・証言を求めない。必要なら目を開ける、呼びかけにかすかに反応する程度の演出に限り、**直人本人の台詞はゼロ**を第一候補とする。

## 任意操作・時系列・SAVE/LOAD（未採用）

- 救出と搬送は連続イベント。現場で喫煙・任意調査・別話題選択を挿入しない。
- 後続S11は**救出直後ではなく、面会可能な後日**。S10終了時に強制的に病室会話へ直結させず、時間経過の短い演出で接続する。
- 2026年10月5日19時頃から10月8日7時頃まで約60時間という時刻は**暫定値**。画面の日時を実装する場合は「三日前」との既知不一致をレビューしてから。
- 直人持参の少量の飲料水・受動通気・ラッチ内部の偶発破損は裏設定として保持。救助場面で過度に科学・医療の詳細を語らない。
- `S10_NAOTO_FOUND`、`S10_AKARI_NOTIFIED`、`S10_TRANSFERRED` を別進行。既読台詞・発見・電話の効果をLOAD後に二重発生させない。進行中のSAVE操作契約はR-01に従う。

## 2026-11-07 作者方針：簡素な救出演出（レビュー前草稿）
本節は旧複雑構造案より優先。S09の反応確認・通報を受け、S10で消防等が扉を開放し、約60時間閉じ込められ衰弱した直人を救出・搬送する。湊は専門救助や医療行為を代行しない。古い扉の留め具が故障していたことは救出後に一言触れる程度で、仕組みや医療数値は詳述しない。直人の長い説明は避け、あかりへの連絡と後日のS11面会につなぐ。S09での人の反応とS10での本人確認は区別し、連続イベントのSAVE/LOAD契約を維持する。本文の旧記述との統一改稿は別工程。

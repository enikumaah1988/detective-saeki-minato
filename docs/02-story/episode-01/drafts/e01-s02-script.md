## 目的・場所・情報の境界

- **場所：** 佐伯探偵事務所。登場は佐伯湊・相澤澪。あかりはS01の依頼受諾イベントを終えて退室済み。
- **開始条件案：** S01で「依頼について」の連続イベントを読了した直後。S01の4話題構成・受諾文・遷移の具体方式はいずれもレビュー草稿であり、確定前提にしない。
- **目的：** 高瀬直人の失踪前の勤務実態を東成ビルサービスに確認すること、同居する高瀬あかりの許可を得て自宅の手掛かりを確認することを、2人で整理する。
- **知識限界：** この時点で担当施設・担当設備区画・旧倉庫・2024年死亡事件・会社の不正の詳細は**判明していない**。勤務先確認はS03、同居宅の資料確認はS04。S02で警察や会社の非公開記録・資料現物を取得した扱いにしない。
- **ゲーム構造：** S01→S02は連続して始まる。短い導入会話の後は場面固有の任意調査・「話す」を可能にする案。S03へ出発する選択は既存の「移動」契約と統合し、独立した「会話を終える」を作らない。

## S02導入：2人の調査方針（新規・未採用）

【背景・演出】

事務所。扉が閉まり、あかりの足音が遠ざかる。澪が席へ戻る。湊は机のメモを一度見直す。

**相澤 澪**

「佐伯さん。まずは、勤務先ですね。」

**佐伯 湊**

「ああ。最後にどこで仕事をしていたのか、確認したい。」

**相澤 澪**

「東成ビルサービス。お兄さんの担当先が分かれば、手掛かりになるかもしれません。」

**佐伯 湊**

「会社が確認した場所も、もう一度聞いておこう。」

【演出】

澪は手元のメモを開く。湊は次の項目に目を移す。

**相澤 澪**

「ご自宅の方はどうしますか？　お二人で暮らしているんですよね。」

**佐伯 湊**

「高瀬さんに相談しよう。仕事の予定が分かるものが残っているかもしれない。」

**相澤 澪**

「そうですね。ご本人に立ち会っていただいた方が安心です。」

**佐伯 湊**

「勝手に探すわけにはいかないからな。」

【演出】

澪がうなずく。湊はメモの「勤務先」の項目にペンで線を引く。

**相澤 澪**

「では、まず会社に連絡を取ってみます。」

**佐伯 湊**

「頼む。俺は聞き取ったことを整理しておく。」

【処理案】

導入会話の読了で「勤務先へ確認する方針」と「自宅はあかりの招待・立会いが必要」という**行動計画**を記録する。ただし、S03の会社側情報やS04の家の資料を既に知ったことにはしない。通常調査へ戻り、任意会話・調査記録・許可場所の喫煙演出を参照可能とする案。

## 通常調査・任意会話（新規・未採用）

### 「話す」→相澤澪／「会社への確認」

**佐伯 湊**

「東成には、何を聞く？」

**相澤 澪**

「高瀬直人さんの勤務予定と、最後に確認された場所ですね。」

**佐伯 湊**

「そうだな。会社が調べた範囲も聞いておきたい。」

**相澤 澪**

「こちらで勝手に決めつけないようにしましょう。」

【処理案】会話後は話題一覧へ戻る。S03で得る情報を先に登録しない。何度選んでも進行フラグは増えない。

### 「話す」→相澤澪／「高瀬さんのこと」

**相澤 澪**

「高瀬さん、ずっとカップを握っていましたね。」

**佐伯 湊**

「ああ。話しに来るまで、ひとりで考えていたんだろうな。」

**相澤 澪**

「……お兄さんの無事が確認できるといいんですが。」

**佐伯 湊**

「まずは、分かることからだ。」

【演出】澪は短くうなずき、メモへ目を戻す。

【処理案】人物の感情を描く任意会話。新しい証拠・信頼度・推理正解フラグは設けない。

### 「調べる」事務所机のメモ

**佐伯 湊（内心）**

「最後に会ったときの様子。勤務先。連絡の記録……。まだ、確かな足取りがない。」

【処理案】取得済みのINV-01相当情報を整理するだけ。T01〜T04の未聴情報を先取りしない。S01で主要情報が未取得のままS02へ来ることは今回の進行案では想定しない。

### 「調べる」飲み物のカップ

【演出】あかりが使っていたカップが机に残っている。

**佐伯 湊（内心）**

「……ほとんど飲んでいかなかったな。」

【処理案】人物の余韻のみ。アイテムとして取得・提示しない。事務所の小道具として背景に描けるか素材検証待ち。

## 「タバコを吸う」— S02任意演出（新規・未採用）

【使用条件案】事務所内、S01のあかり退室後、S02の通常調査中だけ。喫煙可能な既存場所の契約に沿う。未使用でも次へ進める。

【演出】

湊は電子タバコを手に取り、窓の外へ視線を向ける。

**佐伯 湊（内心）**

「帰りが遅くなるとは言っていた。それでも、連絡が途絶えた……。」

【演出】

湊は短く息を吐き、机のメモに目を戻す。

【処理案】未取得情報や正解を明かさず、進行・情報取得・信頼度は不変。再使用では同じ長文を連打せず、既知の範囲内の短い別反応／同段階再表示を検討する。喫煙演出で示した情報を必須化せず、既存喫煙UIの戻り・LOG・SAVE契約に従う。

## 移動・S03への接続（新規・未採用）

【進行案】S02の導入会話読了後、「移動」で「東成ビルサービス」を選べる。導入会話から**自動的にS03へ飛ばさない**。会社への連絡や訪問の具体的なアポイント経緯はS03導入で整合させる。新たな施設を経由させない。

【S02側の出発台詞】

**相澤 澪**

「先方に確認してから向かいましょう。」

**佐伯 湊**

「ああ。まずは話を聞かせてもらおう。」

【演出】

湊はメモを閉じ、立ち上がる。画面が切り替わる。

【処理案】S03に進み、同じ出発会話の二重再生を防ぐ。S04の同居宅訪問をS02で直接解放・強制実行しない。

## 状態・入力・SAVE／LOAD整理（未採用）

| 仮ID／状況 | 効果と禁止事項 |
| --- | --- |
| S02_INTRO_SEEN | 導入読了を記録。S01の依頼受諾を再実行しない |
| S02_PLAN_KNOWN | 調査方針の整理済み。勤務先・住宅の新証拠を取得した扱いにしない |
| S02_FREE_ACTION | 任意会話／調べる／記録参照／喫煙等。操作間でメイン進行を勝手に進めない |
| S02_DEPARTED | 「移動」→東成訪問で一度だけS03へ。実装の保存安定点・内部IDは未確定 |

- AUTOで任意行動や「移動」を自動選択しない。LOG／調査記録を開閉しても進行・情報を更新しない。
- 「話す」対象は澪1人想定。人物選択省略の契約を維持。話題の戻る操作で導入会話を再生しない。
- 台詞・演出の表示は一案。実機素材と実装状態を検証するまではSE/BGM/表情ID、既存30シーンへの反映を確定しない。
- 次のS03は東成本社で湊が藤井・黒田に会い、勤務と担当施設を確認する。澪をS03に同行させる変更はここではしない。

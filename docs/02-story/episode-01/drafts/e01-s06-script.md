# E01-S06「空間の違和感」シナリオ台本 — レビュー前草稿 v0.1

> **状態：全台詞・演出・進行条件が未採用（2026-11-06）。** S05で閲覧済みの現行図面と、許可された地下管理通路の実景を照合する場面。旧倉庫入口の正解提示は**S08**、旧図面の閲覧は**S07**まで行わない。事件設定・情報所持区分は[episode-setting.md](episode-setting.md)と[item-design.md](item-design.md)を優先。新23シーンの制作稿であり旧30シーンの実装変更ではない。

## シーン契約・人物

- **舞台：** 成子坂共同ビル地下、現在使用されている設備室へ続く管理通路。設備区域への立入りには管理者の許可が必要。
- **登場：** 佐伯湊。澪は連絡・調査記録の照合で支援する（通信手段とタイミングは暫定）。建物側の管理者は許可・案内等の安全確認に対応するが、現場の違和感を最初に推理するのは湊。
- **導入情報：** S05の現行平面図INV-04、備品台帳の旧室名INV-05、確認済み設備区画。S04のメモが示した備品確認という予定を含めても、直人の所在はまだ分からない。
- **成果：** 通路の奥行き・壁の位置・設備室の並びと現行図面の間に小さな不一致があり、未確認の空間が存在する可能性に気づく。観察結果をINV-06「湊自身の調査メモ」に記録。
- **禁止：** 壁の向こうに直人がいると断定しない。見えない旧扉を偶然発見・無断開扉しない。改修前の図面の知識を先取りしない。測定値・壁厚・防火区画を実在の技術基準として創作しない。

**佐伯 湊（内心）**

図面の記載部分と現場の突き当たりを比較できる構図に切り替わる。違和感をプレイヤーにも視覚的に提示するが、旧入口や秘密の扉を強調しない。

## 調査ポイント（新規・未採用）

### A「調べる」→通路の突き当たり（主要情報）

**佐伯 湊**

「この壁は、以前からこの位置に？」

【演出】近くで対応している宮原が見える範囲から答える。

**宮原 文雄**

「改修後はこの配置です。以前の細かい間取りまでは、今すぐには分かりません。」

**佐伯 湊（内心）**

「改修後……。通路の長さが変わっていてもおかしくない。」

【処理案】現場にある壁位置を観察したことを記録。図面の室配置との比較資格を得る。宮原による技術断定・旧入口の示唆はしない。

### B「調べる」→設備室の並び（主要情報）

【演出】扉の表示と現在の通路の順序が分かる。立入り許可のない部屋は開かない。

**佐伯 湊（内心）**

「手前の設備室の位置は合っている。それなのに、奥の壁だけが図面と噛み合わない。」

**佐伯 湊**

「図面では、この先にまだ通路の余裕があるように見えます。」

**宮原 文雄**

「そうですね……。今の図面では、それ以上は分かりません。」

【処理案】部屋の配置と突き当たりの対比を調査記録へ反映。正しい区画の位置や隠し扉をまだ特定しない。

### C「調べる」→現行図面の参照（比較操作）

【演出】記録済みの現行平面図の内容と、今見ている通路の輪郭を並べて確認できる演出案。現物の図面を持ち歩いていることにはせず、S05で閲覧した情報の再参照として扱う。

**佐伯 湊（内心）**

「設備室は合っている。通路の突き当たりだけ、合わない。」

**佐伯 湊（内心）**

「図面が古いのか、現場の構造が変わったのか……。どちらにしても、今の図面だけでは足りない。」

【処理案】INV-06の「現行図面と現場の食い違い」を確定。A・Bが未調査なら**この比較だけで手掛かりを取得させない**。反対に、必要情報を見つけたプレイヤーを任意のT01会話に閉じ込めない。

## 「話す」：澪の連絡（補助・新規未採用）

【開始条件案】上記A・Bの観察を取得後、澪への連絡を任意に選べる。またはS07へ戻る際の短い確認会話として扱う。

**相澤 澪（電話）**

「佐伯さん、現場の方はどうですか？」

**佐伯 湊**

「少し気になるところがある。通路の奥行きと、図面の記載が合わない。」

**相澤 澪（電話）**

「改修で変わった可能性はありますね。」

**佐伯 湊**

「ああ。昔の配置を確認したい。」

**相澤 澪（電話）**

「分かりました。今の図面だけでは判断できませんものね。」

【処理案】既知の違和感を整理。澪が先に旧室の位置を推理しない。通話UI・相手選択が既存「話す」契約に合わない場合は、この会話をS07の固定接続へ移す。電話を使わないと必須情報が取得できない構造にはしない。

## 補助の任意調査（新規・未採用）

| 操作 | 反応案 |
| --- | --- |
| 「調べる」壁面の仕上げ | 「最近の仕上げに見える部分もあるが、これだけで壁の向こうは分からない。」という内心。見た目だけで隠し通路を断定しない |
| 「調べる」通路の表示板 | 「今使う区画の表示だけだ。台帳の旧倉庫という名前は見当たらない。」 |
| 「見せる」 | 現行図面・台帳を物理所持の提示物として増やさない |
| 「調査記録」 | INV-04現行図面、INV-05旧室名、INV-06観察メモのみ反映。未読の旧図面は表示しない |
| 「タバコを吸う」 | 設備管理区域内では実際に喫煙しない。任意喫煙ヒント・推理の正解開示なし |
| 再選択 | 観察既読でも記録の更新は一回。AUTOやLOGを開閉しても調査済み状態を変えない |

## S07「旧図面を探す」への接続（新規・未採用）

【開始条件案】壁位置A、設備室並びB、現行図面との比較Cの調査情報をすべて確認。新しい推理問題は追加せず、古い記録を調べるという次の自然な行動で進行。

**佐伯 湊**

「宮原さん。改修する前の図面は残っていませんか。」

**宮原 文雄**

「確認してみます。管理室に記録が残っているかもしれません。」

**佐伯 湊**

「お願いします。この通路が、昔からこの形だったか知りたいんです。」

【演出】

宮原の案内で管理室へ戻る。現行平面図と現場メモは「知っている情報」として保持し、S07での旧図面閲覧につなぐ。

【処理案】INV-06取得をS07への主な前提とする。移動操作や会話区切りの実装方式は既存基本操作に従う。旧図面が見つかることを、このセリフの時点で確定した扱いにはしない。

## 2026-11-07 作者方針反映：S06の目的変更（レビュー前・未採用）
**上記の壁位置・通路奥行きの精密な差分を必須手掛かりとする設計は、この新方針と競合するため差し替え候補とする。**
- S06は現場で、会社・宮原が確認した「現在の設備区画」とその範囲を照合する場面。現行図面と実景の精密な座標比較、隠れた分岐の発見、壁厚・距離の計測は必須ではない。
- プレイヤーが得るのは「予定された区画は確認されたが、旧倉庫は確認済み一覧にない」という事実。ただし旧倉庫が現存し、直人がいると断定しない。
- S07へは旧倉庫の現状・位置を古い記録で確認したい、という自然な動機で接続する。旧図面を参照する前に正解位置を示さない。
- INV-06の旧「壁の位置の不一致」は新方針では必須進行条件から外す提案。フラグ・SAVE/LOAD・既存R03推理契約との整合はレビュー事項。

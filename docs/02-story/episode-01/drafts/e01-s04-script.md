## シーン契約

- **場所：** 東京都中野区の高瀬兄妹の賃貸集合住宅。物件名・番地・間取りは未設定。出入り・家の中の調査は住人のあかりの招待・立会いに基づく。
- **登場：** 佐伯湊・相澤澪・高瀬あかり。直人本人は不在。
- **目的：** 直人の私的な予定メモと通常業務の控えから、遅番点検・備品確認に関連する手掛かりを得る。会社の正式な完了承認記録・機密メール・三崎報告書・旧倉庫入口は入手しない。
- **取得の種類：** あかりが閲覧を認めた範囲の情報を**調査記録に転記**する。原本や端末・手帳の持出し・撮影・無許可の収納開封はしない。
- **接続：** S03で成子坂共同ビルの担当予定を聞いており、その情報とS04の私的メモが照合できる。ただしS05の現場や図面でしか分からないことは先取りしない。

## 導入（新規・未採用）

【背景・演出】

高瀬兄妹の住まい。玄関を開けたあかりは、少し疲れた表情で二人を迎える。生活の様子が残る部屋に、直人本人の姿はない。

**高瀬 あかり**

「来てくださって、ありがとうございます。」

**相澤 澪**

「お邪魔します。無理のない範囲で、見せていただければ大丈夫ですよ。」

**佐伯 湊**

「高瀬さん。お兄さんが仕事の予定を書いていたものはありますか。」

**高瀬 あかり**

「はい。こっちです。兄はよく、予定をメモしていたので。」

【演出】

あかりは自分が普段から確認できる場所に置かれた予定メモを取り出し、テーブルに置く。私室の施錠棚や直人専用端末を無断で調べない。

**高瀬 あかり**

「私に分かるのは、このくらいなんですけど……。」

**佐伯 湊**

「十分です。確認させてもらいます。」

【処理案】

あかりが示した**許可済みの予定メモを閲覧可能**にする。湊が私物の現物を取得したことにはしない。話す相手はあかりと澪の2人になり得るため、複数人物時の「話す→人物→話題」契約を維持。

## 「調べる」：直人の予定メモ（新規・未採用）

【演出】

湊は許可されたメモを手に取り、あかりが見ている前で目を通す。日付や記号は通常の私的な略記であり、謎解き用の暗号ではない。

**佐伯 湊（内心）**

「五日の遅番。成子坂共同ビル……。会社で聞いた予定と合っている。」

**相澤 澪**

「ここに、備品の確認も書いてありますね。」

**佐伯 湊**

「予定された設備点検以外にも、何か確認するつもりだったのか。」

**高瀬 あかり**

「兄は、細かいことも忘れないように書くんです。何の備品かまでは……。」

**佐伯 湊**

「分かりました。こちらで調べます。」

【処理案】

INV-02相当の「遅番点検・成子坂共同ビル・備品確認の予定」を**閲覧で得た情報**として記録。具体的な備品名、旧倉庫の室名、旧通路・入口を示さない。メモの現物・写真は取得しない。未調査でも必須の手掛かりを失わないよう、この閲覧はS05へ進む前の必要情報とする案。

## 「調べる」：通常業務の控え（新規・未採用）

【開始条件案】

あかりが閲覧を許した通常業務の控えが同じ机にある。会社の正式な決裁書・機密の点検原本ではないことを確認したうえで扱う。

**高瀬 あかり**

「こっちも、兄がよく見返していました。」

【演出】

仕事の手順や確認事項を本人が手元用に抜き書きした控え。会社の印章・承認署名・機密図面の複製にはしない。

**相澤 澪**

「この欄、成子坂共同ビルの換気装置について書かれていますね。」

**佐伯 湊**

「『前の対応後も異音あり、再確認』……か。高瀬さん本人のメモだな。」

**高瀬 あかり**

「詳しいことは分かりませんが、兄が気になっていたのかもしれません。」

**佐伯 湊**

「普段から、記録を残す人だったんだな。」

**高瀬 あかり**

「はい。家でも、たまに書き直していました。」

**佐伯 湊（内心）**

「仕事で気になったことがあったのか。だが、これだけで何かの不正があったとは言えない。」

【処理案】

INV-03相当の通常業務控えの**閲覧情報**を記録。業務控えには、成子坂共同ビル地下設備室の**換気装置**について、以前の対応後にも似た異音が再び出たと本人が記した**私的な観察メモ**がある（対象の固有設備ID・確定日付は未決）。2024年の送風機負傷事故の機器・案件と同一とはしない。S12でこの記載を再参照する。会社の正式な修繕完了承認・2024年の事件・架空請求をS04で断定しない。メモの字面は本稿での暫定草稿。会社の正式完了承認や作業の実施有無を示す資料ではない。

## 「話す」→あかり（新規・未採用）

### T01「兄の普段の様子」

**佐伯 湊**

「家では、仕事の話をすることも？」

**高瀬 あかり**

「詳しいことはあまり。でも、何か気になったことがあると、メモを見返していました。」

**佐伯 湊**

「仕事熱心なんだね。」

**高瀬 あかり**

「……そうだと思います。」

【処理案】人物像の補足。必要な予定情報をこの会話にだけ隠さない。再選択で情報の重複取得なし。

### T02「最後に帰宅した日」

**相澤 澪**

「出かけるとき、持っていたものに違いはありましたか？」

**高瀬 あかり**

「特には……。いつもの仕事の荷物だったと思います。」

**佐伯 湊**

「ありがとう。無理に思い出さなくて大丈夫です。」

【処理案】S01で既知の最後の様子を補足。特殊な持ち物・決定的な失踪の原因を新たに設定しない。

**相澤 澪**

「会社の話と、こちらのメモ。今のところ、矛盾はありませんね。」

**佐伯 湊**

「ああ。ただ、予定が分かっても、本人の足取りまでは分からない。」

**相澤 澪**

「次は、実際の現場で確認する必要がありますね。」

**佐伯 湊**

【処理案】取得済み情報を整理する会話。S05で得る図面や現場状況を先取りしない。

## 任意行動・表情（新規・未採用）

| 操作・人物 | 表示案・制約 |
| --- | --- |
| 「調べる」／部屋 | 直人の不在を感じさせる通常の生活用品。無断の私物探索・撮影や新物品取得はしない |
| 「調べる」／許可外の収納 | 湊の内心「ここまでは見せてもらっていない。」で留め、勝手に開封しない |
| 「見せる」 | 予定メモ・控えを勝手に持ち物化して提示物候補へ追加しない。許可済み閲覧と提示を分離 |
| 「タバコを吸う」 | 他人の自宅は喫煙許可場所に含めない。攻略用喫煙・喫煙ヒントなし |
| 「調査記録」 | 取得済みの私的メモ・通常業務控えを**情報**として表示。会社の正式原本と区別 |
| あかり | 不安は続くが、調査に協力できることでわずかに落ち着く。大げさな泣き崩れなし |
| 澪 | あかりに配慮しながら閲覧範囲を守り、重要な情報を見落とさない |
| 湊 | 手掛かりを得ても救出を確約しない。私生活と調査の境界を尊重する |

## S05「担当施設へ」への遷移（新規・未採用）

【開始条件案】

私的な予定メモと通常業務控えの必要情報を閲覧して記録済み。人物の任意話題をすべて聞く必要はない。

**佐伯 湊**

「高瀬さん、見せてくれてありがとう。次は成子坂共同ビルへ行ってみます。」

**高瀬 あかり**

「兄がいた場所、分かるんでしょうか……。」

**佐伯 湊**

「まだ断定はできません。でも、確かめることはできます。」

**相澤 澪**

「何かあれば、私たちからご連絡しますね。」

**高瀬 あかり**

「……お願いします。」

【演出】

あかりは玄関まで二人を見送る。湊はメモを元の場所へ戻し、持ち帰らない。澪とともに部屋を出る。

【処理案】

通常の「移動」から次の訪問へ進む、または調査対象認識後に自然な出発イベントを用いる。専用「会話終了」は設けない。S05は**東成の管理受託先であり本社ではない**成子坂共同ビルへ。管理者の許可を得るまでは自由な設備室への立入りをさせない。S05の場面で湊が中心となり管理者対応し、澪の同行・退場時点は最新のシーン構成と照合する（S05の主要登場人物は湊・管理者）。

## 取得・SAVE／LOAD契約案

- `S04_AKARI_INVITED` はS03の電話イベント等で取得済みとするが、未取得状態で本人の許諾なく家に入る導線は設けない。
- `S04_PLAN_NOTE_READ`／`S04_WORK_NOTES_READ` は**閲覧・情報取得**のみ。資料の持出し・写真撮影・会社の承認証拠獲得には変換しない。
- 既読の話題を再訪しても情報は重複取得しない。「調査記録」閲覧だけで次シーンへ進行しない。
- 選択肢表示・AUTO/LOG・セーブ復帰は既決の通常調査契約に従う。資料閲覧の読了・帰路イベントで同じ台詞や取得を重複再生しない。
- 図面・旧倉庫の存在をS04でプレイヤーに知らせず、S05〜S08で発見と推理の余地を残す。

## 原稿・制作上の制約

4部48場面、第1部16場面という接続を保持する。澪は本話で事務所に残る。事件の核・証言の範囲を変えず、第1部で犯人・兄の沈黙の理由・押す動作の目撃を先取りしない。人物設定の相談稿・素材側の未採用属性を本文へ一括反映しない。プレイ時間約1時間は目標で、機械完走時間による保証ではない。

同じJSON由来の話別一覧は[Free Action参照一覧](free-action-catalog.md)。生成した一覧は制作原稿や共通UI仕様の代わりではない。

## 数字表記

第1話の現行メッセージ・会話・モノローグでは、数量・日時・年齢・階数・住所の番地は原則アラビア数字（原稿では0〜9）で記す（#207）。数値の意味、日時、台詞の口調を変更しない。表示時の全角化は[PC UI](../../01-game-design/pc-ui.md#共通)の既存処理に従い、半角表示への変更は含まない。

人名などの固有名詞、慣用語、物語上の意味・演出意図のある漢数字は維持し、一括置換しない。人数の事実と関係性の表現を切り分けられない「一人」「二人」や、反復・間合いを表す「一度」「一つ」などの判断が難しい箇所は変更せず、対象の原文・場面ID・維持理由をIssue／PRへ報告する。

表記修正は現行の組込データ・導入文と、上表で適用される制作資料の該当箇所へ反映する。版・部の適用範囲を広げず、旧稿や互換用シナリオを一括改稿しない。ver0.03合本の保存原文と現行の部別原稿に表記差がある場合、今回の数字表記は修正済みの部別原稿を参照する。

## 本文・表示に関する共通方針

数量、日時、年齢、階数、住所の番地は原則アラビア数字。固有名詞、慣用句、物語上の意図のある漢数字は一律変換しない。ゲーム内表示の変換は[PC UI](../../01-game-design/pc-ui.md)を参照する。

作者の採用判断と、既存ゲームに実装済みという事実は別。新23シーンの台本作成時は、現在の事件・人物・場所の正本を確認し、既存30シーンの振る舞いを無条件に引き継がない。

# E01-S08「図面の照合」シナリオ・推理問題草稿 v0.1

> **状態：全文・図面配置・回答候補・正誤・補助・遷移とも未採用（2026-11-06）。** S08の「推理する」通常調査からの手動開始、推理画面内「考える」、回答候補選択→明示確定、正解後S09への連続接続という基本操作契約は[actions.md](../../01-game-design/actions.md)に従う。作者承認済みの旧倉庫の事件設定を変更しない。**下記の具体配置は作画前の仮配置**であり、構造・寸法・視認性を検証するまでは公平性の合格判断をしない。旧30シーンの実装対象ではない。

## 目的・演出上の到達点

- 場所：成子坂共同ビル管理室（必要に応じ廊下の観察カットを挿入）。湊と澪。宮原は管理者・安全確認窓口として近くにいる。
- **既知情報：** S05で現行管理図面INV-04／台帳INV-05、S06で現場通路の突き当たり・壁位置と設備室列の不一致INV-06、S07で旧図面と改修履歴INV-07。
- **問いの証明範囲：** 「管理者に**最初に確認を依頼すべき旧分岐の入口候補位置**」を一か所に絞るだけ。旧倉庫が今も完全に残る、直人がそこにいる、無断立入りできる、とは確定しない。

## 推理用の空間関係・図面仕様（作画前の仮配置）

実務上の室名・機器・長さは仮。画像生成や背景素材へ渡す前に、現行図面／改修前図面／通路写真（構図）で**同じ固定基準**を描けることを必須とする。

**固定基準：** 地下管理通路の入口（南側）、通路東側に並ぶ稼働設備室A・B、その扉の順番。入口から見た通路奥（北側）には改修後の突き当たり壁。設備室Bの扉の位置は新旧資料で共通。

- **改修前図面：** 現在の設備室A・Bの扉の並びが同じ。B扉より北側へ通路が続き、**奥の西側へ短い枝通路**が分かれ、その先に「旧倉庫」の室名がある。
- **現行図面：** A・Bの扉は同じ位置。奥の枝通路・旧室名は図示されず、管理動線が突き当たり壁で終わるように表記されている。
- **S06現場観察：** A・Bの並びは図面と一致するが、突き当たり壁は現行図面上の想定より入口寄りに見える。壁面の仕上げと設備の配置で旧分岐側の形が直接見通せず、**普通に見える未確認の扉は存在しない**。
- **改修履歴：** 奥の間仕切り・設備配置の変更は確認できるが、「旧室が現在も無傷で残る」「壁の裏から声がする」ことは記載されない。

仮の模式関係（**建築図面ではない**）：

```text
                   北（通路の奥）
        [旧倉庫]──枝通路（西側）
                      │
                  [旧分岐]
                      │      [設備室B] ← 新旧共通の目印
                  通路│      [設備室A]
                      │
                 入口（南側）

現在：設備室A/Bの並びは維持。B扉より奥の見通しが
      間仕切り・設備配置で変化して旧分岐が不明瞭。
```

**推理の照合規則案：** A・B扉の並びを共通目印にすると、旧分岐は「B扉より奥、通路西側」にしか対応しない。現場において壁と設備配置が変わった範囲はまさにそこ。入口付近の西壁や設備室A扉脇、現行の通常出入口には該当しない。見かけの通路長だけで答えを確定せず、旧図面の枝通路と**共通のB扉**を合わせて判定する。図面の縮尺・壁厚や改修位置を後で数値設計して矛盾が出た場合はこの正解を採用しない。

## 固定導入会話（新規・未採用）

【演出】管理室。湊が現行図面の閲覧メモと、宮原から見せてもらった改修前図面の内容を照らす。澪が資料の見やすい位置を整える。

**相澤 澪**

「改修前には、今の図面にない分岐があったんですね。」

**佐伯 湊**

「ああ。だが、今も通れるとは限らない。」

**相澤 澪**

「図面の縮尺が違うだけ、ということはありませんか？」

**佐伯 湊**

「それも考えたい。どの位置が一致していて、どこから食い違うのか……。」

【演出】湊はS06で観察した設備室の並びと突き当たりを思い返す。

**佐伯 湊（内心）**

「現場を確かめてもらうなら、候補は絞っておきたい。」

【処理】**推理対象「旧分岐の確認位置」認識済み**を設定。通常調査に「推理する」を表示する（未取得情報があっても、この時点から外観を変えず表示する）。「推理可能！」などの正解タイミング通知は出さない。

## 「推理する」入口（手動／未採用）

**情報不足時の反応：**

**佐伯 湊（内心）**

「今ある情報だけじゃ、場所を絞れないな。現場で見た位置と、図面の違いを確認しよう。」

【処理】短い独白後に通常調査へ復帰し、誤答扱いはしない。図面・観察が揃っても表示色や文言を変更せず、同じ入口で問題へ進む。

**情報充足時の中立的な問い：**

**佐伯 湊（内心）**

「改修前の分岐を今の配置に当てはめるなら、管理者にどこを確認してもらうべきだろう。」

## 回答候補（新規・未採用。図面上の3か所を表示する位置推理）

| 仮候補ID | 画面上の位置表示 | 正誤 | 選択理由・検証条件 |
| --- | --- | --- | --- |
| A | 通路の入口近く、西側壁 | 誤答 | 共通基準の設備室A/Bより手前で、旧図面の分岐位置と合わない |
| B | 設備室Bの扉より奥、西側の改修された壁面付近 | **仮正解** | 旧図面の枝通路の分岐位置と設備室Bの位置関係が合い、現場の見通しが変わった区域に重なる |
| C | 設備室Aの扉の脇、東側 | 誤答 | 稼働設備室Aの出入口と重なり、旧図面の西側分岐に対応しない |

**回答操作：** 地点を一つ選択し、別の「回答を確定」で判定。選択しただけでは進行しない。調査記録や「考える」から戻っても未確定選択とフォーカスを維持（LOADをまたぐ復元は約束しない）。候補を情報の取得状況に応じて色分け・削除しない。**設計図の絵がA/B/Cの説明と一致しない限り、この正誤は仮置き**。

### 誤答A

**佐伯 湊（内心）**

「そこは旧図面でも、設備室より入口側だ。分岐の位置とは合わない。」

【処理】同じ問題へ戻る。選択を解除。ペナルティ、ヒント自動開示、正解候補削除なし。

### 誤答C

**佐伯 湊（内心）**

「ここは今も使っている設備室の側だ。旧図面の分岐は、その反対側だったはずだ。」

【処理】同上。選んだ根拠の不足だけを説明して正解位置を指差さない。

## 推理画面内「考える」任意補助（未採用）

通常調査の常設「考える」は増やさず、推理画面でのみ表示。押すごとに**本人の内心を既存の台詞ウィンドウ**で1段階表示し、読了後同じ問題へ戻る。1段階目の後は同じ位置のラベルを「もう少し考える」にし、最終段階後は消す。開示した内容は通常LOGへ初回一度だけ記録。誤答回数・経過時間で自動強化しない。

- **段階① 着眼点：** 佐伯湊（内心）「図面の違いを探す前に、変わっていないところを押さえよう。」
- **段階② 比較対象：** 佐伯湊（内心）「設備室の並びは同じだ。そこを目印にすれば、新旧の通路を比べられる。」
- **段階③ 判断方法：** 佐伯湊（内心）「旧図面の分岐と、現場で配置が変わった範囲を、同じ目印からたどってみるか。」

補助だけで新たな図面・壁の情報を付与せず、選択肢ID・候補名・最終回答を明かさない。段階③が事実上の正解提示にならないかレビュー対象。

## 仮正解B → 結果会話 → S09（未採用）

【演出】湊が図面上の一か所を示す。ここでは壁を叩いたり破壊したりしない。

**佐伯 湊**

「設備室の位置は変わっていない。昔の分岐は、その奥の西側にあったはずだ。」

**相澤 澪**

「間仕切りが変わった場所と重なりますね。でも、今もそこが通れるかどうかは……。」

**佐伯 湊**

「分からない。だから、管理者に確認してもらおう。」

【演出】湊が宮原に候補位置を説明する。

**宮原 文雄**

「分かりました。ここは管理側で安全を確認します。必要なら専門の方にも来てもらいます。」

**佐伯 湊**

「お願いします。中の様子が分からない以上、無理はできません。」

【処理】推理の**回答成立**と、**結果会話読了によるS09連続イベント開始**を別段階として扱う。ここでは直人の居場所・生存確定は付与しない。プレイヤーが結果会話から任意調査へ戻り、再度同じ推理を解くループは作らない。S09で実地確認・反応・救助担当への連絡につなげる。

## 情報・保存・入力契約案（未採用）

| 仮状態 | 確定条件 | 扱い |
| --- | --- | --- |
| S08_TARGET_RECOGNIZED | 導入の比較対象を認識 | 通常調査の「推理する」入口を表示 |
| S08_EVIDENCE_READY | 現行図面・台帳・現場観察・旧図面・改修履歴の必要情報 | 入口から問い／3候補へ入れる。既読任意会話は不要 |
| S08_POSITION_ANSWERED | 選択Bを「回答を確定」して判定成立 | 正解回答済み。結果会話の未読先頭へ原子的に移動 |
| S08_CONFIRMATION_REQUESTED | 宮原へ確認を依頼する結果会話を読了 | 管理側確認のS09へ連続接続。直人の生存はまだ未確認 |

- 未選択の確定は入力不能（誤答ではない）。誤答は非進行で同じ問いに復帰。LOG/記録閲覧・補助で回答を勝手に確定しない。
- SAVE/LOADは既存flagsと安全なnodeIdで復帰。回答済みで未読結果会話がある場合、問いを再要求せず未読台詞から続行する。回答選択中の一時カーソルは保存必須にしない。原子的な確定途中でSAVEを受け付けない。
- S08は管理室等での推理のため、**喫煙による攻略補助なし**。追加の通常調査「考える」コマンドもなし。
- **重要：** 固定基準の図面描写が実際の作画で同じ視点・位置関係を表現できない場合、候補・正誤を再設計し、S08はレビュー未合格とする。

## 後日の厳格レビュー対象

1. A/B/Cの3位置を図面と現場画像から同一粒度で識別できるか、候補Bだけが合理的か。
2. 通路奥行きの違和感が「図面の縮尺・壁厚・改修後の建築」だけで説明できる場合の反例。
3. 台帳室名と旧図面が独立した手掛かりになっているか、INV-04〜07を適法に取得・閲覧できるか。
4. 正解後の宮原対応・管理側権限・消防等との連絡をS09へつなぐ安全性。
5. 推理中の戻る／AUTO OFF／LOG・考えるの復帰、結果ノード分割、既存30シーンSAVE互換。
6. 絵・文字のヒントが図面にない事実や確定していない生存情報を先取りしていないか。

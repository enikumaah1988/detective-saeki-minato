制作原稿、組込データ、ゲームコードは別の成果物。原稿の相談・採用状態をコードの現状だけで変更しない。旧稿の合本・部別原稿も編集せず保持しており、ver0.04だけを唯一の全文原稿とは扱わない。

## シナリオ制作時の参照順

1. 現行『消された記録』は本文正本から、対象シーンの本文・操作台本と実装差分を読む。凍結稿・実装仕様・改稿履歴を分け、実装済みという理由だけで人物設定候補を採用しない。
2. 作品共通の人物設定は[人物設定と採否](../03-characters/人物設定.md)を入口に、必要な項目の合意記録へ進む。合意記録v0.02・v0.03は合意部分と解釈案・未採用案を含み、相談稿v0.01の全項目を承認するものではない。
3. 人物資料が参照する「第1話_現行設定.md」「progression.md」や相談稿のP1〜P4の根拠は旧稿『灰色の証言』の範囲で読む。特に「澪が事務所に残る」という旧稿の制約を現行30シーンの出番へ一括適用しない。人物名・属性・口調・呼称は対象版の出典と採否を確認し、不明なら補完せず判断事項として残す。

旧稿・相談稿・合意記録は保持する。人物資料から旧稿への参照を解消し、人物別プロフィールを整える作業は別PRで扱う。

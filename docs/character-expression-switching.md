# 会話に応じた立ち絵の表情（Issue #53）

2026-10-20。既存の感情別画像を使用し、台詞と反応に合わせて表情を切り替える。画像の新規生成・人物配置・台詞・進行条件・保存形式は変更しない。

## 指定方法

`src/data/scenario/revisionData.ts` の会話行に `expressions` を指定する。キーは人物ID、値は `src/data/presentation.ts` に登録済みの表情ID。

```ts
{ speakerId: 'mio', text: '……', expressions: { mio: 'amused', minato: 'surprised' } }
```

- 話者以外の反応も指定できる。表示中の人物だけに適用し、人物の追加・位置・対面前の表示条件には影響しない。
- 表情は同じ会話列の後続行へ引き継ぐ。戻す場合はその人物へ `normal` 等を明示する。
- 別の会話列や選択メニューでは場面の既定表情に戻る。別の話題をどの順で読んでも表示が変わらない。
- 文中の単語や句読点から感情を自動推測しない。原稿の解釈に応じた指定をシナリオデータへ置く。
- 背景だけの行では人物を出さない。非表示・未対面・電話のみの人物も追加しない。
- 3人表示の湊の `front-normal`、あかりの `right-sad` は維持。新画風の追加方向素材がないため、この指定を汎用の別表情で置き換えない。

今回は日常・あかりの相談と依頼受諾、黒田と宮原の証言、警察の確認、直人の告白と証言の決意、兄妹の対話、終幕を対象とし、17会話列・50行に指定を追加した。対象は湊・澪・あかり・黒田・宮原・奥村・瀬川・直人の8人。指定のない会話は従来の場面既定表情を使う。

## 接続と保存互換

`buildRevision.ts` が会話列内の表情を各ノードの `expressions` に確定し、`selectSceneStage` が場面から得た人物の表情だけを上書きする。共有のシーン定義は変更しない。

表情はノードIDから導出できるため、GameState・SaveData version 2へ保存項目を増やさない。既存ノードID・シーンID・自動保存の進行単位も維持し、途中の旧セーブから直接ロードしても同じ表情を再現する。

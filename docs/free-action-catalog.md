# フリーアクションと全サブメニュー一覧

2026-10-13修正後。4部46場面の現行本編から自動出力。条件付きの項目、任意の持ち越し、人物を見る、移動、推理の選択肢も含む。条件が揃う前から全項目が同時に出るわけではありません。

「話す／聞く」はメイン→人物→話題。「見る／調べる」はメイン→対象。「戻る」は各一覧にあり、一階層ずつ戻ります。人物名が複数コマンドに出るのは、それぞれ見る対象・会話相手になるためです。

通常のメッセージ後は選択元の一覧に留まります。必要なやり取りが終わって場面が変わる場合は次の場面へ進みます。あかりの退出前は「話す→あかり→挨拶」で会話を閉じ、任意の話題はそれまで選べます。

表示条件の取得IDは機械版JSONと一致します。「常時」はその場面内での意味です。旧セーブ互換用ノード、独立DEVモック、使われなくなった進行用コマンドは一覧に混ぜません。

# Windows UI担当・保存時点の進捗

作業ブランチ: work/ui-windows。基点: main 34c36df。

## 完了

- 喫煙可否と取得情報に応じた喫煙ヒント、専用挿絵、元画面への復帰。仮シナリオ向け文面。SaveData version 2を維持。
- DEV専用の調査・建物内移動・屋外地図モック。地図選択→確認→暗転→到着メッセージ→Free Action。中止、現在地、画像失敗、キーボード操作に対応。
- 選択肢全体、上部3ボタン、会話ウィンドウ、調査記録のSVG素材枠。文字・操作はHTML/CSSで維持。話者40px・下線最低160px。
- 調査記録の4分類、独立スクロール、固定詳細タイトル、人物画像と説明の横配置。
- 持ち物スマホ・電子タバコ・名刺の画像を組み込み。制作側art/main-charactersのbf16880由来、1024四方透過PNGを変更せずコピー。src/data/itemImages.tsで本編とDEVプレビューの参照を共通化。

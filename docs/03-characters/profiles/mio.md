# 相澤 澪（あいざわ みお）

**32歳／佐伯探偵事務所の助手・湊の相棒**

## 人物像
柔らかく知的で、周囲の小さな変化に気づき、必要なことを自然に行動へ移せる人物。人が安心して話せる場を整えるのが得意で、相手の話を丁寧に受け止める。お淑やかさと華やかさがあるが、ただ控えめなだけではない。

**相手が話せる環境を整えるのは得意だが、自分の望みは後回しにする。** 湊にも異議を言える仕事相手であり、相棒として自分の判断を持つ。「自分の疲れを後回しにする」という別案は取り下げられており、人物の核には含めない。

## 話し方・振る舞い
一人称は「私」。柔らかく丁寧な口調で、必要なことは簡潔にはっきり伝える。湊を「佐伯さん」と呼ぶ。親しい相手への軽口も敬語を崩しすぎずに交わし、反対意見を述べるときも感情的にならず、根拠や別の見方を示す。

メモを取る、髪を耳にかける、静かに相手を見るなどの所作がある。気づいたことを行動へ移すが、いつも同じ所作を繰り返すわけではない。

## 人間関係
**佐伯湊**：互いの力量を認め、気遣いも異議も伝えられる、信頼の深い仕事上のパートナー。湊の考えを先回りして肯定するだけでなく、誤りや飛躍があれば指摘できる。恋愛関係の有無、出会い、共に働いた期間、雇用上の細部はまだ定めていない。

**依頼人・関係者**：話しやすい空気を作り、相手に合わせて丁寧に接する。親切さと調査上の判断を両立させる。呼称は原則丁寧だが、過去の原稿だけに登場する相手の呼び方を、今後の全場面の固定規則にはしない。

## 得意なこと・好み・日常
コーヒーやお茶に詳しく、飲み物を通じて場の空気を整える。記録・資料の整理だけでなく、照会や現場での確認、別の仮説の提示など、自分で考えて動ける。湊の苦手な部分を補う名助手であると同時に、独立した判断を持つ人物。

## 外見・服装
長い暗い茶色のウェーブヘア、柔らかな目元、細身の体型。落ち着きと華やかさを併せ持つ。ダスティブルーのジャケット、白いブラウス、淡い青灰色のスカート、灰色のパンプス、控えめなアクセサリーと腕時計。具体的な身長は未設定。

画像制作時の採用素材や表情差分は[作画プロフィール](../../04-art/characters/mio/profile.md)を参照する。

## 過去・内面・制作側だけが知ること
自分の望みを後回しにする傾向は、今後の物語で掘り下げられる人物の核となる。ただし、その望みの具体的な内容、事務所で働く理由、過去の経験、家族、抱えている秘密は**未設定**。もっともらしい動機や重い過去を自動的に補わない。

澪自身の視点で物語を進める構想はあるが、採用未決定。湊との関係を恋愛として扱うかどうかも決めていない。

## 今後の物語で大切にしたいこと
- 配慮深さを、受け身や無条件の同意と同一視しない。
- 湊の相棒として自分の意見を持ち、必要なら異議を伝える。
- 自分の望みを後回しにする性質を、勝手に疲労や自己犠牲の設定へ置き換えない。
- 私生活や過去、将来の視点変更は、後続エピソードで検討できる余地として残す。

# 相澤澪 — 人物別プロフィール試作

既存情報を制作向けに整理した試作。設定の新規決定・台本の改稿指示ではない。[人物設定の入口][index]の参照順・A〜F区分に従う。第1層の項目IDは第2層の台帳へ対応する。**Aは明示的な作品共通合意、Bは現行本文で観察できる描写**。Bを恒久的な性格へ自動昇格させない。C＝旧稿限定、D＝解釈、E＝未採用・保留・撤回、F＝未確定・矛盾・根拠未整理。

年齢や作画資料の既存属性は、作品共通の承認根拠未整理であっても削除・未採用化しない。作画範囲での承認済み／候補／確認待ちは別記する。外見・衣装・画像の採用記録そのものは04-artを参照し、本書で二重管理しない。

## 第1層：シナリオ制作向けプロフィール

### 基本情報・役割

相澤澪（あいざわ みお）。湊と働くパートナーで、現行Episode 01では依頼人対応だけでなく、資料手配・図面照合・現地合流・緊急連絡・推測への留保を担う。探偵助手・相棒・記録係という既存記載は保持するが、資格・正式な雇用関係までは補完しない（I04、[S02][s02]・[S05][s05]・[S14][s14]）。**32歳は既存設定として継続使用／作品共通の承認根拠未整理**として保持する（I05）。

### 人物の核となる性格

**合意済み・作品共通（A）**の核は「相手が話せる環境を整えるのは得意だが、自分の望みは後回しにする。湊にも異議を言える仕事相手」。湊とは「互いの力量を認め、気遣いも異議も伝えられる、信頼の深い仕事上のパートナー」である（I01・I02）。相手を支える力と、自分の判断で意見を述べる力を一緒に持つ人物として読む。

「自分の望みは後回しにする」という合意は、[作画profile][artI]で**取り下げ済み**の「自分の疲れを後回しにする」とは別項目。疲労を隠して献身する人物という設定を、この合意から復活させない（I14）。自分の望みの具体的な内容や、後回しにする理由は未確定のままである。

### 価値観・行動原理

**現行描写（B）**では、あかりに温かいものを出し、連絡先を預かる一方で、会社への連絡・記録・図面の照会を自ら申し出る（[S01][s01]・[S02][s02]）。旧図面を照合して調べる理由を示し、証拠がまだないことも添える（[S05][s05]）。湊の三崎への想像には記録から分かる範囲に留めるよう促し、事故説も残す（[S14][s14]・[S19][s19]）。気遣いと慎重な仕事が同時に描かれているが、それを「優しさとは正確な連絡と記録だ」という未採用の内面案の承認にはしない（I06・I07・I15）。

### 口調・一人称・呼称

### 他人物との関係性

湊との対等に意見を交わせる仕事上の関係はAである。ここでの対等性は判断・気遣い・異議を交わせるという範囲を指し、雇用上の地位や私生活・恋愛関係の確定ではない（I02）。あかりへの温かい応対と救助後の家族への連絡、会社・管理側との資料手配は現行の行動として参照できる（B、[S01][s01]・[S02][s02]・[S06][s06]・[S10][s10]）。単なる湊の思考の代弁者として置かず、実際に申し出る・照合する・反対意見を述べる場面を読む（I06・I07・I10）。

### 習慣・好み・所作

**現行描写（B）**では、コーヒーの焙煎の違いを伝え、湊や奥村に出している（[S01][s01]・[S29][s29]・[S30][s30]）。コーヒー・お茶に詳しい、メモを取る・髪を耳にかける等は[作画profile][artI]の既存記載として保持する。本文のコーヒーの実例だけから、お茶の知識や好み全体のA承認を推定しない（I11）。[S11][s11]で依頼人の椅子を戻す動作も確認できるが、毎回同じ気遣いの所作を強制する規則にはしない。

**作画範囲**では、長い暗い茶色のウェーブヘア等の外見方向、ダスティブルーのジャケット、白いブラウス、淡い青灰色のスカート等の採用記録がある。青系配色・表情所作の設定シート採用と、後続の画風調整・個別画像の確認状態を分ける。旧チャコール・グレージュ配色へ機械的に戻さない（I12）。

### 現行Episode 01での役割と行動

S01であかりを迎え、S02で会社・記録・図面の照会を引き受け、S05で資料を持って合流する。S06〜S10は緊急連絡・図面の確認・救助担当や家族への連絡を担う。S11では失踪依頼と別件調査を区切り、会社の正式な了承が必要だと指摘する。その後は代替仮説や確認項目を出し、S14・S19では湊の推測に歯止めをかける。S26・S27では自分たちが確認できる範囲と警察に渡す疑問を整理する。S30は兄妹の近況を伝え、日常の会話へ戻る（I06・I07・I10・I16）。

### 執筆時に避けたい誤解・描写

相手が話せる環境を整える力を、接客だけ・無条件の同意だけに狭めない。核の「自分の望みは後回し」と、撤回済みの「自分の疲れを後回し」を混ぜない。現場へ来ない人物という恒久規則も作らない（I13・I14）。湊への異論や現地合流を、そのまま恋愛・同居・雇用上の対等さの証拠にしない（I02・I15）。現行で知らない警察内部情報や他人の内心を、察しの良さで知っていることにしない（I16）。

[作画profile][artI]・[作画入口][art]を外見・衣装・所作と採用画像の詳細の参照先にする。[本文入口][current]の最終凍結判定と、[解消履歴][resolution]・[全編整合レビュー][continuity]・[総合検討][review]を照合し、当時の候補・残論点を自動改稿指示にしない。旧稿の日常を一部再利用した現行導入の範囲は[開始導入と来訪前の日常][intro]に限り、旧稿の薄めのコーヒーや帳簿を開く進行を一括継承しない。

今回確認したのはGitHub上の記録であり、元チャット全体や未収録の承認は独立に検証できていない。32歳等の共通根拠、口調・呼称の恒久的な範囲、資格・雇用関係、動機・恋愛・視点切替は保留。他人物への展開前には、主体性が具体場面から読み取れるか、取り下げ表現と合意の核を混同していないか、作画承認と共通根拠未整理の表示が分かるかを独立レビューで確認する。

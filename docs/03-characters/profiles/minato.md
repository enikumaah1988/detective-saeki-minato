# 佐伯湊 — 人物別プロフィール試作

既存情報を制作向けに整理した試作。設定の新規決定・台本の改稿指示ではない。[人物設定の入口][index]の参照順・A〜F区分に従う。第1層の項目IDは第2層の台帳へ対応する。**Aは明示的な作品共通合意、Bは現行本文で観察できる描写**。Bを恒久的な性格へ自動昇格させない。C＝旧稿限定、D＝解釈、E＝未採用・保留・撤回、F＝未確定・矛盾・根拠未整理。

年齢や作画資料の既存属性は、作品共通の承認根拠未整理であっても削除・未採用化しない。作画範囲での承認済み／候補／確認待ちは別記する。外見・衣装・画像の採用記録そのものは04-artを参照し、本書で二重管理しない。

## 第1層：シナリオ制作向けプロフィール

### 基本情報・役割

佐伯湊（さえき みなと）。現行Episode 01では佐伯探偵事務所で依頼を受け、直人の足取りと記録の不一致を調べる主人公の探偵。名前・役割の既存記載と現行の自己紹介・行動を参照する（M04、[S01][s01]）。**38歳は既存設定として継続使用／作品共通の承認根拠未整理**。今回未採用にも新規確定にもせず保持する（M05）。

### 人物の核となる性格

**合意済み・作品共通（A）**の核は「他人には選ぶ余地を渡すが、自分の困り事は一人で抱え込む」。澪とは「互いの力量を認め、気遣いも異議も伝えられる、信頼の深い仕事上のパートナー」である（M01・M02）。自分の困り事を抱え込む性質を、他人へ一切頼まない規則に変えない。現行の[S02][s02]では澪に連絡・資料の仕事を任せ、[S14][s14]では異論を受け止めている。

### 価値観・行動原理

**現行描写（B）**では、あかりに最後に確かめられた事実を尋ね、記憶の曖昧な部分を無理に埋めさせない。調査を引き受けても結果の保証はせず、調べる順番を示す（[S01][s01]）。捜索では所在が未確定でも危険の可能性があれば連絡を急ぎ、救助は専門職へ任せる（[S06][s06]・[S09][s09]・[S10][s10]）。記録の不一致と不正、面談予定と実際の面会、面会と転落原因を分ける（[S12][s12]・[S18][s18]・[S26][s26]）。これは本話の制作参考で、そう振る舞う過去・個人的動機まで確定した説明ではない（M06・M07・M14）。

### 口調・一人称・呼称

**現行の実例（B）**として、澪には短い常体と軽口がある。一人称「俺」は[S02][s02]の仕事分担、[S23][s23]・[S29][s29]で確認できる。一方、会社・依頼人には敬語を使い、[S15][s15]には一人称「私」もある。「どの相手にも俺・常体だけ」と固定しない。作画資料の「静かで短い常体、乱暴ではない」という既存記載も保持するが、全作品の口調の一括承認にはしない（M08）。

| 相手・場面 | 現行の実例 | 使い方の参考と限界 |
| --- | --- | --- |
| 澪・日常 | [S02][s02]「コーヒーは持参で？」 | 仕事を任せた後の軽口。危機の場面に機械的に持ち込まない |
| 依頼人 | [S01][s01]「見せられる範囲で構いません」 | 開示の範囲を相手に残す。全質問の決まり文句にしない |
| 会社・技術者 | [S12][s12]「承知しました。確認事項をまとめます」、[S15][s15]「私が見たいのは」 | 相手・公的な場に合わせた敬語・一人称の実例 |
| 奥村 | [S21][s21]「奥村さんは、いつもそこを間違えませんね」 | 「奥村さん」と呼ぶ。親しい経緯・過去事件は未確定 |
| 直人 | [S09][s09]「高瀬直人さん。聞こえますか」、同場面の「高瀬さん」 | 救助対象への呼び掛け。親しさの程度を名前だけで補完しない |
| 三崎 | [S18][s18]「三崎さんが確認を求めたことは分かります」 | 記録で知る人物。生前の知己としない |

澪への直接の呼称「澪」は[旧稿第3部][old3]の電話場面等で確認できる（C）。上表の現行例には直接呼び掛けがないため、旧稿の呼称を今回Aへ昇格させない（M09）。

### 他人物との関係性

澪との信頼と異議を交わせる関係はA。奥村との現行の接点は、確認事項を渡し、警察が開示できない情報の線を尊重する関係である。奥村は早合点を戒め、湊はその慎重さを言葉にしている（B、[S21][s21]・[S27][s27]・[S29][s29]）。長い旧知の具体的な由来や出会いは不明のまま。あかりには聞き取りと連絡で向き合い、直人の救助直後には事情聴取より搬送を優先する（M02・M06・M10）。

任意BARでは怜子に仕事の詳細を話さず、杏奈の接客に礼を返す。ここを事件情報源や恋愛関係の証拠にしない（B、[操作台本後半・任意イベントA/B][op2]）。

### 習慣・好み・所作

**現行描写（B）**には、澪のコーヒーを飲み、日常の軽口を交わす場面がある（[S01][s01]・[S30操作「調べる：コーヒー」][op2]）。「コーヒー、特に澪の淹れるものを好む」、電子タバコ、口元に手を当てる等は[作画profile][artM]の既存記載として保持する（M11）。現行本文5部・操作台本2件では電子タバコを使う場面を確認できていないため、新たな喫煙場面や頻度は作らない。

**作画範囲**では、うねる黒髪・眼鏡・現在の衣装と画風を採用した2026-10-13の記録がある。白シャツと緩い黒ネクタイは最新採用の記録を参照し、途中の眼鏡なし・旧ノーネクタイへ戻さない。長身・細身・無精髭等の既存記載、身長未決、個別画像の確認状態は元資料で確認する（M12）。

### 現行Episode 01での役割と行動

あかりの依頼を受け、会社と現場の確認範囲を調べ、澪の資料照合と管理側の協力で捜索先を絞る（S01〜S10）。救出後は失踪調査を区切り、会社の正式な手続きの下で記録の不一致を確かめる（S11〜S18）。調査で得た疑問を奥村へ渡すが、警察内部の聴取には同席せず、黒田の供述を知ったことにはしない（S19〜S29）。終幕では澪から兄妹の近況を聞き、三崎について分からないことも残す（S30）。根拠はM06・M07・M10・M15。

### 執筆時に避けたい誤解・描写

合意した核から、依頼人のためなら越権する、澪に頼らない、常に単独行動する、という規則を作らない。旧稿の澪の事務所残留や帳簿を開く結末は現行の恒久設定ではない（M13）。「人を待たせた過去があるから探偵になった」等、未採用動機を具体的な過去へ展開しない（M14）。参照作品の人物像を土台とする合意は、その作品の経歴・台詞・秘密の移植許可ではない（M03）。作者とプレイヤーが知る黒田の供述を湊の既知情報にしない（M15）。

### 旧稿・未採用案・未確定事項への参照

旧稿の適用版は[版別の参照表][old]に従う。[相談v0.01][consult]の「既存記載」「読み取り」「提案」「未確定」は旧稿の根拠と検討の区分であり、現行本文の承認ではない。湊の望み・恐れ・弱さ・過去由来の仮説、澪とのすれ違い案は残したままM13・M14から辿る。v0.02の関係性の解釈案の全項目を、v0.03で明示された範囲より広く承認済みにしない。

### 作画・実装との境界と残る確認

[作画profile][artM]と[作画入口][art]を外見・衣装・所作の詳細の参照先とする。採用シート・個別画像・新画風・ゲーム接続は別状態。本書のために作画資料の「確認待ち」を解消しない。[本文入口][current]の最終凍結判定、[解消履歴][resolution]・[全編整合レビュー][continuity]・[総合検討][review]を照合し、途中の未解決表示を改稿指示にしない。

今回の整理はGitHubに残る承認記録の確認であり、元チャットの発言全体・未収録の個別承認を独立に検証していない。38歳等の作品共通根拠、口調・呼称の全作品での適用、奥村との過去、経歴・恋愛・秘密は判断保留。次の人物へ展開する前に、作画の承認済み属性と共通設定の根拠未整理を同時に示す表記、台帳の粒度と読みやすさを独立レビューで確認する。

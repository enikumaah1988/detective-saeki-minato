## 2. 人物紹介

軽い口調と人懐っこい笑顔が特徴の情報屋。「鳴海ユウ」という名前で活動し、普段は20代後半ほどの青年の姿をしている。

しかし、それが本当の姿なのかを知る者はほとんどいない。実際の年齢は20代とも、それ以上とも噂され、性別さえ定かではない。名前も容姿も振る舞いも、すべてが仮の姿である可能性がある。

冗談や軽口を交えながら人との距離を縮めるが、容易に本心を明かさない。嘘の情報は売らない一方、知っている真実をすべて明かすわけでもない。

## 4. 性格・価値観

**基本性格**：明るく軽妙で、冗談を交えた会話を好む。ただし、これも「鳴海ユウ」としての振る舞いであり、素の人格まで確定するものではない。

**長所・強み**：軽口や笑顔で人との距離を縮め、必要な場面では普段の軽さを消して冷静に対応できる。

**短所・弱み**：何を考えているのか分かりにくく、重要なことでもすべてを説明するとは限らない。

**価値観・信念**：嘘の情報は売らない。ただし、真実をどこまで明かすかは自分で判断する。

**行動原理**：情報を提供する一方、自分が明かす範囲を選ぶ。その判断の背景や本当の目的は未設定。

合意記録と相談稿は意味内容を維持してこのディレクトリへ移動した。未確定の内容を一つの確定プロフィールへ無理に統合せず、項目の確認先を一本化している。あかり・直人などの話別の年齢・職業等は、旧稿内の採用範囲を[Episode 01の設定（旧稿「灰色の証言」）](../02-story/episode-01/第1話_現行設定.md)で確認する。現行稿への継承は項目ごとに本文・採用根拠と照合する。

## 採用状態と適用範囲の読み方

以下は項目を整理するための区分。索引への掲載はAへの昇格を意味しない。人物全体に一つの区分を付けず、設定項目ごとに根拠とともに記録する。

| 区分 | 意味 | 扱い |
| --- | --- | --- |
| A | 作品共通の明示的な確定設定 | 明示的合意の文言・対象項目・適用範囲を示す |
| B | 現行Episode 01の本文で確認できる描写 | 本文・操作台本の節／シーンIDを示す。全作品での固定属性や内面の断定へ広げない |
| C | 旧稿限定の設定・描写 | 旧稿名・版・部／場面を明記し、現行稿へ自動継承しない |
| D | 既存描写からの解釈・推測 | 描写そのものと読み取りを分ける。承認済み設定として使わない |
| E | 未採用・保留・撤回された案 | 未採用／保留／撤回を補記し、後続の明示的採用なしに復活させない |
| F | 不明・未確定・資料間の矛盾 | 欠けている根拠や矛盾する出典を併記し、推測で埋めない |

採用状態と独立して、**適用範囲（作品共通／現行Episode 01／旧稿／作画）**を記す。同じ項目に複数の範囲があれば各範囲の根拠を別に示す。作画上の承認は「作画で採用・承認済み」と明記して保持し、Aの作品共通承認やBの本文描写へ一括変換しない。

既存設定として継続使用されていても作品共通の承認根拠が未整理の属性は、「既存設定として継続使用／作品共通の承認根拠未整理」と付記して保持する。単に未採用へ落としたり削除したりしない。例として湊38歳・澪32歳は[旧稿設定](../02-story/episode-01/第1話_現行設定.md)と各作画profileに記載がある一方、合意v0.02・v0.03では年齢を確定していない。既存記載を保持しつつ、その合意だけで作品共通の年齢を追加確定しない。

将来の記録単位は「設定の文言／採用状態／適用範囲・版／根拠のファイル・節・シーンID／合意日・承認範囲／旧稿差分・未決点」。作者設定、プレイヤーへの開示、各人物が取得済みの情報はさらに区別する。

## 新旧稿・承認範囲を混同しないための注意

1. **宮原の立場**：現行は会社側の窓口、旧稿はビル管理人・動作目撃者。[現行S03・S12・S13](../02-story/episode-01/erased-records/README.md)と[作画profileの版別注意](../04-art/characters/miyahara/profile.md)、[旧稿設定](../02-story/episode-01/第1話_現行設定.md)を分ける。
2. **直人の失踪理由**：現行は旧保管室への閉じ込めと救助。旧稿は黒田の脅しを受けた潜伏。[現行第2部](../02-story/episode-01/erased-records/dialogue/part-02.md)と[旧稿設定「事件」](../02-story/episode-01/第1話_現行設定.md#事件)を混ぜない。現行の2026年の閉じ込めと2024年の三崎事件は因果的に無関係（[構成表](../02-story/episode-01/erased-records/story/outline.md)）。
3. **三崎の問題意識**：現行は部品型番・交換・払出し・差し戻し等の修繕記録。旧稿は負傷社員への責任押し付けと報告書。[現行第3部S13〜S18](../02-story/episode-01/erased-records/dialogue/part-03.md)と[旧稿設定「事件」](../02-story/episode-01/第1話_現行設定.md#事件)を分ける。
4. **澪の同行**：相談稿・合意記録の事務所残留は旧稿の制約。現行[第1部S05・S06](../02-story/episode-01/erased-records/dialogue/part-01.md)・[第2部S07〜S10](../02-story/episode-01/erased-records/dialogue/part-02.md)には同行がある。共通人物像だけを理由に出番を変更しない。
5. **作画の承認**：各profileの明示的な承認・撤回・同期待ちを保持する。外見・衣装・シートの承認から性格・経歴等の全属性を承認済みにしない。[作画入口](../04-art/README.md)と[制作ガイド](../04-art/production-guide.md)の用途別状態を確認。
6. **本文末尾の候補・残論点**：人物見直し候補、人物再評価、整合レビュー、第1部末尾第3パスは本文と区別。[本文入口の読み分け・最終凍結判定](../02-story/episode-01/erased-records/README.md)、[実装差分](../02-story/episode-01/erased-records/implementation-deltas.md)、[解消履歴](../02-story/episode-01/erased-records/review/consistency-resolution-20261026.md)と照合し、現在の確定設定や自動改稿指示にしない。
7. **知識の境界**：作者・プレイヤー・各人物の知識は別。特に[第4部S22・S25](../02-story/episode-01/erased-records/dialogue/part-04.md)・[第5部S28](../02-story/episode-01/erased-records/dialogue/part-05.md)の警察内部の供述を、その時点の佐伯・澪が知る情報にしない。相手から聞いたこと、見たこと、推測、会社・警察の非公開情報をシーンごとに確認する。

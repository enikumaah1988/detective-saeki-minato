# 作品共通の人物設定と採否

人物像・性格・口調・呼称・関係の参照入口。事件内で判明する事実・登場条件は[物語](../02-story/README.md)、画風・外見・画像は[作画](../04-art/README.md)へ分離する。

## 合意済みの範囲

根拠は[合意記録v0.02](人物プロフィール_合意記録_v0.02.md)と[合意記録v0.03](人物プロフィール_合意記録_v0.03.md)。この二つは全人物・全属性の一括承認ではない。

- 湊の核は「他人には選ぶ余地を渡すが、自分の困り事は一人で抱え込む」。
- 澪の核は「相手が話せる環境を整えるのは得意だが、自分の望みは後回しにする。湊にも異議を言える仕事相手」。
- 二人は互いの力量を認め、気遣いも異議も伝えられる、信頼の深い仕事上のパートナー。参照作品に近い人物像を土台にしつつ、本作の人物として育てるという方針を保持する。
- 経歴や細かな設定は本作用に相談して決める。参照作品の設定・経歴・台詞をそのまま確定事項へ移さない。

## 未採用・未確定

[相談稿v0.01](人物プロフィール_相談稿_v0.01.md)には他人物の内面・重い過去・個人的目標等の提案を含む。湊・澪の動機候補、年齢、経歴、出会い、共に働いた年数、恋愛の有無は上記合意から確定しない。口調・呼称も、相談稿・既存台詞・作画profileの記述を新たな全体承認とみなさない。

合意記録と相談稿は意味内容を維持してこのディレクトリへ移動した。未確定の内容を一つの確定プロフィールへ無理に統合せず、項目の確認先を一本化している。あかり・直人などの話別の年齢・職業等は、採用範囲を[Episode 01の設定](../02-story/episode-01/第1話_現行設定.md)で確認する。

## 作画資料との境界

[作画profile群](../04-art/characters)はPhase 2-Bで内容を保持して04へ移動した。外見・衣装・向き・画像採用の正本として参照し、そこに含まれる人物像やストーリー同期待ちの属性を自動的に確定しない。本話で澪が事務所に残ることは[話別進行](../02-story/episode-01/progression.md)の制約であり、共通人物設定から新しい外出展開を追加しない。

# タイトル画面

2026-10-19、ユーザーが背景07を了承しタイトル制作を依頼。タイトル画面は仮実装。作品名・英字は将来のロゴが入る領域の仮表示とし、`TitleScreen`の`logoSrc`で文字表示をロゴ画像へ差し替えられる。ロゴ自体は未制作。文字・UIは背景へ焼き込まない。背景07は `src/assets/images/ui/title-office-night.png` へ移動し正本を一本化。追加の画像生成なし。

## 動作

- 通常起動: タイトル画面。上部に仮の作品名・英字、中央のやや下にNEW GAME／CONTINUE／SETTINGSを縦並びで表示（ユーザー指定により、下端10%の配置から2行分＝168基準px上へ移動）。各行は小さなアイコン＋ラベル。ユーザー指摘により横並びを撤回し、元の縦方向の並びを維持した。アイコンは既存のSVG描画方式を拡張し、ラベルと読み上げ名を維持。
- NEW GAME: 通常URLではEpisode 01「消された記録」の導入4段落・仮扉・来訪前の日常操作を経て、全30シーンのS01本文へ進む。タイトルに話名を表示する。旧稿をCONTINUEした後も、タイトルへ戻った次のNEW GAMEは「消された記録」の先頭へ戻る。既存の保存枠を消去しない。本編開始前はStoryPlayerをマウントせず、背面の進行・オートセーブを起こさない。
- CONTINUE: 既存のAUTO・手動3枠を選ぶ。保存内のscenarioIdをカタログ全体で検査し、「消された記録」・旧稿「灰色の証言」・第1部限定版など保存した元のシナリオへ復帰する。新稿へ自動変換しない。空枠は選択不可、保存なしは説明表示。`readSlots`／`loadSlot`を使い、旧保存の移行・復元検査・保存枠ごとの履歴を引き継ぐ。破損データはエラー表示し、上書きしない。復帰ノードを初期状態としてマウントし、復帰だけではオートセーブしない。本編中のLOADも同じカタログで検査し、保存した元のシナリオと履歴へ復帰する。
- SETTINGS: 既存のスライダーで文字速度4段階、BGM/SE音量0〜100。保存キーは本編と共通。音の再生を追加したものではない。
- 各ダイアログはEscapeまたは戻るで閉じ、操作元メニューへフォーカスを戻す。Tab/Enterで操作可能。
- 本編MENUのRETURN TO TITLEから確認を表示。「保存していない進行は失われます」と説明し、初期フォーカスはBACK TO GAME。そのままEnterを押すかEscapeで取り消せる。RETURN TO TITLEへフォーカスを移してEnterを押すかクリックすると確定し、本編をアンマウントしてタイトルへ戻る。確認中はMENUによる進行停止を維持。既存のセーブ・設定は保持し、再開用の初期状態・履歴・プレビューをクリアする。次のNEW GAMEは先頭・履歴なし、CONTINUEは保存枠から復帰。
- 開発サーバーの`?dev=1`のみ本編直行を維持。通常の`?scenario=...`は指定シナリオのタイトル画面から開始する。既存ブラウザーテストの本編前提URLには`?dev=1`の指定が必要。

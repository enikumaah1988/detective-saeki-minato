# 保存・設定・履歴の操作

画面操作の正本。保存スキーマ・移行・キーは[保存データ設計](../05-architecture/save-data.md)、開始・再開は[タイトル画面](title-screen.md)を参照する。

- MENUは左側にSAVE／LOAD／RETURN TO TITLE、右側に文字速度・BGM/SE音量を置く。展開中は背面の進行・自由行動操作を止め、閉じると位置を維持して再開する。
- SAVEは手動3枠の最新を1へ入れ、旧1→2、旧2→3、旧3を破棄する。中央の「セーブしました」OK後にMENUを閉じ、追加通知は出さない。
- LOADはAUTO1枠・SAVE1～3を選ぶ。空枠は選択不可。中央の「ロードしました」OK後に状態を適用してMENUも閉じ、保存ノードの先頭ページから再開する。読んでいない情報を補充しない。
- 保存失敗・形式破損・未知の保存位置は画面で案内し、破損JSONや既存枠を正常な新規データとして上書きしない。
- 文字速度は70／35／15／0msの4段階。BGM/SEは0～100、刻み1の連続range。矢印キーと再読み込みに対応する。音量設定の保存と、音素材・再生の実装は別であり、BGM/SE再生は未接続。
- 会話履歴は会話窓右上から開く。最大2000件を各保存枠のスナップショットに保持する。旧ロードマップの500件・別キー保存という説明を現行仕様にしない。
- 履歴表示中は文字送りを止め、最新位置を表示する。閉じるへ初期フォーカスを置き、Tabはモーダル内部、Escapeで閉じる。閉じるとノード・ページ・表示位置を維持して文字送りと呼び出し元のフォーカスを戻す。
- タイトルへの復帰確認は同幅のBACK TO GAME／RETURN TO TITLE。初期フォーカスはBACK TO GAME、Enter／Escapeは取消、明示的な確定だけで本編を終了する。保存枠・設定は保持する（#51／PR #59）。

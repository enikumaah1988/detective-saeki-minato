# 移動と屋外マップ

本編へ接続済みの移動UIを対象とする。独立DEVモックは[開発用プレビュー](../06-development/exploration-ui-mock.md)へ分離する。

- 屋内は部屋名の一覧、屋外は建物名称に「前」を付けた場所から「他に移動する」で地図へ進む。ピン選択は場所情報の表示だけで、「ここへ移動」で初めて移動を確定する。取消・Escape・戻るで位置・時刻・進捗を変えない。
- 地図を開くと通常HUDの人物・会話・コマンドを隠す。上部MENUと重ならないよう地図に余白を設ける。見出しは「移動先を選択」、エリア名は「西新宿周辺」。地図下部の重複する現在地・案内フッターは設けない。
- 現在地も情報を見るために選択できるが、現在地への移動確定は無効。他の地点は選択と確定を分ける。地点名と現在地の状態表示を区別し、現在地ラベルを重複させない。
- 地図は中央寄せcoverで枠を満たし、画像とピンを同じ座標レイヤーで切り抜く。4地点をピンで表示し、会社だけを別の下部リストへ分離しない。画像失敗時も場所名・選択・移動・取消を使用でき、Tab／Enterで操作できる。
- 本編の訪問先制限は既存の一本道を維持し、「今回の訪問先」を表示する。新しい自由再訪シナリオは追加しない。
- 会社の所在地・架空名称・入居階は[ロケーション設定](../02-story/episode-01/第1話_ロケーション設定.md)と[企業設定](../02-story/episode-01/東成ビルサービス.md)が制作上の正本。地理データ中の実在施設名から会社設定を推測しない。
- 地図内の「上が北」や出典表示を追加し直さない。出典・利用条件は[地図制作資料](../art/maps/geographic/README.md)と対応JSON等で保持し、公開条件や今後のライセンス一覧は別途確認する。

# PC版の表示仕様

対象はPCの通常GAME・Free Action・共通ウィンドウ。既存の採用事項を整理したもので、新しいUIの採用やコード変更ではない。操作は[actions](actions.md)、地図は[map](map.md)、保存・設定は[save-and-settings](save-and-settings.md)を正本とする。

## 共通

- 1920×1080・16:9を基準とし、小さいPC画面では同じ比率で縮小する。寸法は基準px。青黒・チャコール、オフホワイト、落ち着いた真鍮色を使う。
- 背景、人物、会話／コマンド、上部HUDの順。Free Actionでは会話窓を隠す。DEV操作は通常プレイに出さない。
- UIフォントはZen Kaku Gothic New。ローカルWOFF2の400・700を配信し、代替順はYu Gothic、Hiragino Kaku Gothic ProN、sans-serif。font-display: swapで本文を隠さず、読み込み後の再計測で既読文字位置を維持する。フォントの著作権・ライセンスは[src/assets/fonts](../../src/assets/fonts)に保持する。
- メッセージ以外の操作ウィンドウ見出しは共通フォント・36px・太さ600（#48／PR #59）。作品ロゴ・扉絵の意匠とは区別する。
- 表示時の数字は全角、漢数字は維持。ただし話単位の指定表記は半角の「Episode 01」（#47）。原稿、内部ID、保存値、パスは変換しない。

## 会話窓

| 要素 | 採用値・動作 |
| --- | --- |
| 位置・幅 | 水平中央、幅90%、下部フローティング |
| 高さ・下余白 | 320px・24px |
| 背景 | 青黒・不透明度68%。他パネルと分離 |
| 話者 | 40px、太さ600、行間1.25、真鍮色。左48px・上28px |
| 名前下線 | 最小幅160px、文字幅に追従、高さ2px。本文まで12px |
| 本文 | 38px、太さ400、行間1.5、最大3行。名前のない地の文・心の声も本文の開始位置を合わせる |
| 送り記号 | 全文表示後に右下の28px SVG三角形。動きを減らす設定では点滅を止める |

本文は実際のフォント・幅・明示改行で改ページする。文字送り中の操作は現在ページの全文表示、読了後は次ページ、最終ページ読了後の操作で次ノードへ1回だけ進む。途中ページでは取得情報やフラグを更新しない。日本語・結合文字・複合絵文字を欠落させない。通常会話だけに話者名と下線を表示し、思考・喫煙メッセージでは表示しない。

## HUDとパネル

- MENU・調査記録・タバコを吸うは左上。HUD文字35px、アイコン55px、間隔15px。場所・日時は右上の2段、36px。上24px・左右32pxを基準とする。
- 通常会話とFree Actionでは本編の上部操作を使用できる。導入・終了・扉絵等では場面に応じて隠す。履歴入口は会話窓があるときだけ表示し、会話窓のないFree Actionには出さない。MENU・記録・地図・喫煙等の表示中に背面を操作させない。
- MENUと調査記録は共通の青黒の面・真鍮の枠を使い、上端をHUD下端から16px以上離す。ゲーム領域とHUDの実寸から位置を更新する。
- コマンド群はゲーム領域の右側・垂直中央。右余白8%、幅420px、最小行高88px、間隔12px、内側16pxは従来の仮採用寸法。長文は縮小せず折り返す。非表示項目の空行を作らない。見出しを含む項目群を中央配置する。
- コマンドとサブメニューの操作文字36px。項目名とNEW・既読・調査済み等の補助表示を同じ行で区別し、重ねない。枠・アイコンの制作資料は[作画入口](../04-art/README.md)を参照する。

## 人物・調査記録

- 人物構成・位置はシーン側で指定し、話者交代やFree Action切替だけで自動移動しない。2人は左右、3人は左・中央・右を明示。警察は瀬川・湊・奥村、兄妹場面はあかり・湊・直人。安易な水平反転はしない。
- 表情の明示指定は[表情運用](../04-art/character-expressions.md)に従う。表情変更は人物の追加や登場条件の変更を意味しない。画像の正式採用とは別。
- 調査記録の順序は人物・証拠・出来事・持ち物。取得前の内容や未解放枠は見せない。出来事の時系列と情報の取得順を区別し、未対面の顔はUNKNOWNとする。名前のない受付モブを人物記録へ追加しない。
- タブ・一覧の選択文字36px、本文32px。左右の一覧・詳細は独立スクロール。表示・利用条件はゲーム状態から導出する。写真受取の中央表示はOK後に所持へ反映する。

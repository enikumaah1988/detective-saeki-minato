## システム・UIの違い

以下はUIフォルダに対して、キャラクター側のコードにある機能。差分の方向は「UI側の新変更」とは逆なので注意する。

| 領域 | UIフォルダ | キャラクター側のコード |
| --- | --- | --- |
| 人物・シーン | 基本は単一人物Stage | scenes / sceneId、複数人物と配置の検証 |
| Free Action | 基本の選択肢と条件判定 | 専用mode、0件時の復帰、親メニュー指定、戻る時の更新防止 |
| 会話再生 | 基本の文字送り | ページ分割、再生状態・入力世代の管理、二重入力対策 |

## 統合時に調整する点

1. UIフォルダを丸ごと上書きコピーすると、調査記録・入力対策・シーン処理等を失う可能性がある。最新のUI作業先を特定してから、変更意図ごとに取り込む。
2. 正式人物素材は src/assets/images/characters/<id>/ にあるが、現在の presentation.ts は旧 src/assets/characters/ の湊・澪を参照している。素材制作済みと本編組み込み済みを区別する。
3. 正式素材の通常表情は neutral、現行の登録は normal。対応を明示して組み込む必要がある。
4. 直人・あかりの採用資料と本編シナリオは別管理。直人のprofileにもストーリー同期待ち・ゲーム用個別素材未制作とある。
5. 表示サイズ・配置・トリミングと人物ID／表情IDを、素材側とUI側の共通の受入条件にする。

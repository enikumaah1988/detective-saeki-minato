# 調査・移動UIモック

2026-10-11。正式シナリオ作成中の操作・表示確認用。屋外移動の画面構成と操作方式はユーザー採用済みで、正本は docs/pc-game-ui.md。調査の拡大表示・具体的な場所・素材・寸法の細部は試作。本編への接続済みを意味しない。

## 今回の対象

- DEVから開く独立したモック。本編シナリオ、GameState、SaveData version 2、証拠・情報取得処理は変更しない。
- 既存のPC UI仕様に合わせ、右8%・幅420px・項目88px・間隔12px・本文36px、選択150ms、通常のDialogue Windowを再利用する。
- 人物素材の組み込みとサイズ変更は対象外。事務所では既存の湊を左に表示し、拡大表示では人物を隠す。

## 仮採用の流れ

「調べる」は対象一覧を表示。事務所では机・窓、ロビーでは案内板・出入口を選べる。
対象を選ぶと中央の拡大表示と下部Dialogueを表示し、対象一覧を隠す。説明の完了後は一覧へ戻り、その対象をモック内で確認済にする。Escapeによる中断では確認済にしない。再選択可能。

建物内の「移動」は右側に移動先一覧を表示する。事務所→ロビー、ロビー→事務所／建物の外へ。現在地は除外する。「戻る」は移動せずFree Actionへ復帰する。
行き先選択後は150msで暗転、300ms後に到着先を表示。到着メッセージ完了後、その場所のFree Actionへ復帰する。移動中は追加選択を受け付けない。
動きを減らす設定では暗転アニメーションを止める。

事務所は既存画像の拡大、ロビーとその対象はCSSによる代替表示。正式素材・場所・文章は未決定。

## 屋外移動地図（採用仕様の操作モック、2026-10-11）

- 屋外の「移動」は通常HUD・人物・Dialogue・右側コマンドを隠し、地図を全面に表示する。
- 中央左に仮地図、右に選択場所の画像・説明・「ここへ移動」、右上に「× 戻る」を配置する。青黒・オフホワイト・真鍮色の既存テーマを使う。
- 探偵事務所・駅前・喫茶店の3地点。現在地は白と「現在地」表示で区別し、選択できない。選択中の行き先は真鍮色。
- ピンの選択だけでは場所を変えない。画像と説明を更新し、「ここへ移動」の選択演出完了で暗転・到着へ進む。
- 「× 戻る」／Escapeでは移動せずFree Actionへ戻る。再度開いた際は行き先選択をリセットする。
- 事務所の地図ピンは事務所前の屋外を指す。そこから「建物に入る」→ロビー→事務所と進む。
- モックでは全地点が判明済み・移動可能。正式な解放条件、移動時間、シナリオイベントは接続しない。
- 仮地図と駅前・喫茶店の素材は src/dev/assets/ に保存し、DEVモックを開いた時のみ読み込む。本番ビルドからはモックと素材を除外する。
- 画像が読めなくても、代替表示でピン・場所名・移動操作を維持する。クリックとTab／Enter／Escapeに対応する。

右パネルにはまず「移動先を選択」を案内し、ピン選択後に場所の情報を表示する。ラベルは画像に焼き込まずHTMLで表示する。

## 受入基準・テスト観点

- 対象一覧・拡大表示・移動先一覧・到着後で必要なUIだけが表示される。
- 調査対象を変更でき、完了した項目のみ確認済になる。
- 移動取消では現在地を維持し、往復後もモック内の確認状態を保持する。
- 到着先に合わせて現在地・背景・調査対象を切り替える。
- 屋外で現在地を選択できず、ピン選択時・取消時には場所を変更しない。3地点を往復できる。
- 本編を停止・保持し、閉じると元の会話位置へ戻る。LocalStorageへ書き込まない。
- 1920×1080／1366×768、クリック／Enter／Escapeで操作でき、画面崩れや実行エラーがない。

正式実装時は行き先の解放条件・取得情報・再調査の台詞・移動時刻をシステム側と照合する。今回のモックでは接続しない。
接続待ちの情報と検証項目は [屋外移動のシステム接続メモ](outdoor-movement-integration.md) を参照。

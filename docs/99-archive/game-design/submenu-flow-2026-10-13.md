# サブメニュー復帰・人物観察・場面進行の修正

最新の会話統合・選択肢の流れは [選択肢の流れの修正](conversation-flow-2026-10-13.md) を優先する。画像サイズはデザイン側で対応する。
ユーザーの「すぐにこれらを直して。直したあと、今あるフリーアクションとそのサブメニューの全ての一覧を作ってほしい」を受けて反映。原稿ver0.03の事件・証言・46場面は維持する。

- 通常の話題・観察・調査のメッセージ後は、選択元の話題/対象一覧へ戻す。「戻る」は一階層ずつ。途中の一覧を保存しても同じ階層へ復元する。
- 「見る」に、その場にいる人物を追加。対面・認識前の人物を解放せず、名乗り前は女性/管理人などの表示を保つ。表情や仕草を描写し、証言や隠された事情は付与しない。観察時と人物別の話題一覧では対象の人物へ視点を合わせ、同じ部屋の背景を保つ。電話の相手をその場にいる観察対象にしない。
- 「仕事に戻る」「兄の事情を確かめる」などの独立した進行コマンドを削除。必要なやり取りが終わると、同じ部屋で続く会話へ自然に接続する。場面が変わる場合は新しい場面のメニューになる。
- 任意の話題は相手が同じ部屋にいる間、次の場面でも選べる。あかりが退出するP1-05/P4-10は、最後に「話す→あかり→挨拶」で会話を閉じる。解放直後の任意話題を選ぶ時間を残す。
- 移動は「移動→外に出る/部屋名」。建物前・マップの階層は維持。別室への到着は「応接室に入った。」「旧事務室に入った。」など、部屋名で表示する。
- 同一場面の主コマンド/話題ID重複を検査。人物を「見る」と「話す」の両方の対象にするのは役割の異なる選択。持ち物の一覧は実際の使用先UIと同じ遷移先の重複を除いて出力する。
- 旧保存の独立進行サブメニューは、対応する会話へ移行。version2を維持し、未読の名乗りや証言を移行時に追加しない。

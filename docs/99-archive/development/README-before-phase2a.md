## 本編の操作

会話枠・背景・人物のクリック、またはEnterで文章を送る。文字送り中は現在ページを全文表示し、完了後は次ページ、最終ページでは次の会話へ進む。最大3行に改ページし、情報取得は会話の最終読了時に処理する。

「聞く」「話す」は相手を選んでから話題を選ぶ。「調べる」で受付や管理人を認識すると会話対象が開く。考える・整理するは必要な場面だけ表示。移動は部屋名または「外に出る」から建物前へ、そこからマップへ進む。地図のピンと「ここへ移動」で目的地外観へ、入室で調査を再開する。任意話題を残したまま次へ進める。

| 機能 | 現行の動作 |
| --- | --- |
| MENU | SAVE／LOAD。AUTO１枠＋手動３枠、文字速度４点、BGM/SE音量０〜１００の連続調整 |
| ロード | 中央に「ロードしました」。OKでMENUも閉じ、保存ノードから再開 |
| 会話履歴 | 会話窓右上の「履歴」から開く。Free Actionでも同位置。読了済みの最大２０００件を枠ごとに保持 |
| 調査記録 | 人物・証拠・出来事・持ち物。未取得の内容は表示しない |
| 人物の顔 | 対面済みの制作済み人物は顔、未対面はUNKNOWN。未作画人物は代替表示 |
| 持ち物 | 写真の中央受取表示。所持と場面条件に合う項目に「使用する」 |
| タバコを吸う | 場所の可否に応じた静止挿絵と取得状況からのヒント。正式挿絵と動きは台帳で管理 |

推理は各3問。誤答はヒントから同じ問へ戻り、前の正解を巻き戻さない。

## セーブ・設定・履歴

LocalStorageでAUTO１枠と手動３枠を管理する。SAVEは最新を１枠目に置き、旧１→２、旧２→３、旧３を破棄。「セーブしました」のOK後にMENUを閉じ、追加通知は出さない。LOADはAUTO／SAVE１〜３を選択し、空き枠は選択不可。AUTOは本編の場面または話題段階の切替時だけ上書きし、通知しない。通常の文章送りや質問追加、ロード自体では保存を連発しない。

保存先は `detective-saeki-minato.slots.v1`。管理コンテナはversion 1、各枠のゲームデータは従来のSaveData version 2。旧 `detective-saeki-minato.save.v1` は初回に手動枠へ移行し、旧キーも保持する。旧version 1・2の復元に対応。ゲームデータの保存スキーマは変更していない。

`GameState` はシナリオID・ノードID・フラグ・既読話題・調査済み対象・取得情報を持つ。背景や人物はノードから導出する。既存ノードIDを維持し、旧の一括質問の取得済み情報を新しい分割質問へ移行する。

文字速度・BGM/SE音量は独立キー、履歴は各枠のスナップショットに保持する。旧履歴はシナリオID・ノードIDが一致する場合に移行する。会話のロードは保存ノードの先頭ページから再開する。履歴の開閉・MENUの開閉は現在ページと文字送り位置を維持する。保存容量不足・形式破損・未知の保存位置は復元せず画面で案内する。クラウド同期は未実装。

通常プレイでは下部DEV欄を非表示にする。開発サーバーの `?dev=1` でだけモック・プレビュー・シナリオ切替を表示する。既存モック検証と旧セーブ互換ノードは保持。詳細は[UIと保存枠の仕様](../game-design/ui-save-slots-2026-10-14.md)。

## 起動・ビルド・検証

通常環境では対応するNode.jsとnpmを用意する。簡単に起動する場合：

- Windows：ルートの `start-local.cmd` をダブルクリック（またはPowerShellで `.\start-local.cmd`）。
- Linux：リポジトリで `sh ./start-local.sh` を実行。

初回は `npm ci` で依存関係を導入するためネット接続が必要。起動後、ブラウザーで http://127.0.0.1:5187/ を開く。終了は起動した画面でCtrl+C。ポート5187が使用中ならエラーで終了するので、使用中のサーバーを止めて再実行する。別のポートを使う場合はWindowsで `.\start-local.cmd -Port 5197`、Linuxで `sh ./start-local.sh 5197` を実行する。依存関係を更新した後は `npm ci` を再実行する。サーバーは自分のPCからのみ接続できる。

個別に実行する場合：

```bash
npm ci
npm run dev -- --port 5187 --strictPort
npm run build
node --test --test-isolation=none tests/*.test.mjs
```

このWindows作業領域の既存ランタイムを使用する場合：

```powershell
pwsh -File tools/scenario-windows.ps1 dev
pwsh -File tools/scenario-windows.ps1 build
pwsh -File tools/scenario-windows.ps1 test
```

ブラウザーテストには外部Playwright/Chromiumが必要。`SAEKI_PLAYWRIGHT_PATH`にモジュール、`SAEKI_PART1_URL`に本編URL、`SAEKI_BASE_URL`に旧デモURL（`?scenario=gray-testimony-part1-demo`付き）を指定する。未設定ならブラウザー項目だけスキップする。検証用Viteはロジックテストと異なるキャッシュ領域を使う。

改訂実装はロジック89件・ブラウザー37件を別実行で確認し、型チェック・ビルドも成功。PC Chromium 1920×1080・1366×768の結果で、他環境や公開条件の合格ではない。今回の台帳整理は文書変更のみ。

## データ・表示とDEVの境界

作品データは `src/data/scenario/`、素材登録は `src/data/presentation.ts`、再生・保存・記録は `src/features/story/`、型は `src/types/` に分離する。作品の画像パスを共通の進行処理へ埋め込まない。

DEV欄には旧デモ・調査記録プレビュー・調査／移動モック・喫煙プレビューを残している。旧デモの澪が依頼人という設定、駅・喫茶店・仮資料は新本編の正本ではない。旧デモの「考える」単独表示は互換検証用で、新本編は任意質問を残す。

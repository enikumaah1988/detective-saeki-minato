# 第1話「灰色の証言」事件設計たたき台

作成：2026-10-11。同日、ユーザーが提示内容に「それで行こう」と回答。会社の責任隠し、告発しようとした社員の殺害、兄の沈黙・面会・失踪、管理人を介した接触の筋をver0.01へ採用する。人物名は役割名のまま。階段からの転落は暫定案で、具体的な殺害の仕組みと決め手の証拠は引き続き検討中。文中の未決・残課題を解決済みと解釈しない。

## 事件を一文で

会社で起きた社員の負傷を隠そうとした上司が、告発しようとした社員を殺した。兄は上司の嘘を知っていたが、妹を支える仕事を失うことを恐れ、目撃を伏せた。

兄の職業の暫定設定は変更しない。会社の業種と負傷事故の作業内容は未決。工事の架空請求・資金流用の話とは別案。

## 過去の出来事：仮の時系列

1. 会社で社員が負傷。管理職は会社側の問題を隠し、本人の不注意という説明に合わせるよう周囲へ圧力をかける。
2. 被害者は事実を明らかにしようとし、成子坂共同ビル内で管理職と話す。
3. 対立の中で管理職が被害者を階段で突き落とし、死亡させる。本人が足を滑らせた事故と説明される。方法の物理的成立と当初判断の根拠は今後詰める。
4. 兄は管理職が現場から出てくるところを見る。殺害そのものは見ていない。
5. 管理職は兄へ仕事を失う恐れを与え、兄は何も見ていないと答える。管理職は現場にはいなかったと証言する。

会社が負傷者へ責任を押しつけ、次に死亡した被害者にも責任を押しつけた、という反復を事件の軸にする。二つ目の殺人事件は設けない。

## 今回の失踪：仮の時系列

1. ビルの取り壊しが決まり、会社の古い書類の整理も進む。兄は過去の沈黙が最後まで固定されると感じる。
2. 兄は休暇を取る案を置くが、妹へ事情を言わず、普段の出勤と同じ時間に外出する。休暇取得は未承認。
3. 管理職へ本当のことを話してほしいと求めるが、妹の暮らしを持ち出して脅される。
4. 兄は帰宅を恐れ、管理職とつながりのない安宿に身を隠す。連絡すれば妹が捜しに来ると考え、連絡も避ける。これは合理的な正解でなく、恐怖から判断が狭まった本人の選択として描く。
5. 自分だけで証言を裏づけようと兄が古いビルを再訪し、その足取りが探偵へつながる。

取り壊しは、建物に残る物だけでなく、過去を知る人と記録が散る最後の機会とする。証拠がすべて偶然そこに保管されていた構造にはしない。

現段階では、出入りの記録が残る具体的な理由、資料の保管・取得経路、死亡の事故性を否定する証拠が不足している。嘘と動機だけで犯人と断定しない。以下の三役を満たす証拠設計を次に行う。

## 証拠設計の残課題

1. **現場にいたこと**：兄と独立した記録・証言で裏づける。記録の長期保存を都合よく置かない。
2. **不注意による事故ではないこと**：当初の記録を再検討して分かる事実を用意する。階段からの転落だけでは他殺としない。
3. **管理職の行為が死亡に結びつくこと**：接触、方法、時刻を結ぶ証拠が必要。資料の所持と告発の動機だけでは不足。

殺害方法と証拠は一組として設計し直せる。成立しなければ転落案に固執せず、ver0.01の証言の食い違いを保てる方法へ変更する。警察の手続きの細部は主題にしないが、推理の飛躍は残さない。

## 感情の着地点

兄は妹を支える仕事を守ろうとして、他の人へ責任を押しつける嘘に加わってしまった。妹は兄の恐れを知り、気づけなかった後悔を抱く。兄の選択の責任を妹へ移さず、今後は一人で決めず話す余地を残す。

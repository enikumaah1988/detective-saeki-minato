# EXP-001 Issue駆動型AI開発の検証

状態: 計画（未実施）
作成日: 2026-10-09
関連: [開発方式の変遷](../evolution.md)

## 目的
人間が詳細な実装プロンプトを毎回作らず、CodexがGitHub Issueと既存仕様から作業を進められるか確認する。

## 仮説
目的、対象範囲、仕様書リンク、受入条件が明確なIssueを与えれば、Codexは実装方針の調査、実装、テスト、PR作成まで自律的に進められる。

## 対象候補
Free Actionの小規模な改善。着手前に現行実装を確認し、既に完了している機能の重複実装を避ける。対象Issueは別途決定する。

## 手順
1. 既存の docs/pc-game-ui.md と関連コード・テストを確認する。
2. 一つの変更をIssue化し、目的・非対象・受入条件を記載する。
3. CodexにIssueを指定し、作業開始からPR作成まで委任する。
4. 自動テストとレビューで品質を確認する。
5. 人間の追加指示・手戻り・制約を記録する。

## 成功条件
追加の詳細な実装指示を最小限に抑えつつ、受入条件を満たすPRと検証結果が得られること。仕様の曖昧さは独断で補わず、必要な判断を人間へ返せることも評価する。

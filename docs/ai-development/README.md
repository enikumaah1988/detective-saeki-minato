# AI開発方式・学習記録

このディレクトリはゲーム制作（Track A）とは別に、AIを活用した開発体制の変化（Track B）を学習資産として残す。

- [evolution.md](evolution.md): 開発方式の段階、移行理由、実績と計画
- [experiments/EXP-001-issue-driven-development.md](experiments/EXP-001-issue-driven-development.md): Issue駆動型の自律開発実験（計画）

## 記録の原則
- 実施済み、確認済み、計画、仮説を明確に区別する。
- 成功だけでなく、失敗、追加指示、手戻り、制約を記録する。
- 変更の理由と比較対象（以前の開発方式）を残す。
- Issue、PR、コミット、テスト結果へのリンクを付ける。
- AIが記録案を作り、人間が判断理由と解釈を確認する。
- 機密情報や認証情報を記載しない。

ゲーム制作の進行を優先し、記録作業は必要最小限とする。

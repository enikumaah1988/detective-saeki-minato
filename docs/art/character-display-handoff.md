# 人物表示基準：組み込み側への引継ぎ
2026-10-12。既決事項の照合。新しい配置の採用・ゲーム実装変更は行わない。

## 合意済みと未採用の区分

| 内容 | 状態 | 引継ぎ |
|---|---|---|
| 男性100%・女性90% | ユーザー合意済みの暫定表示ルール | 画像ファイルを縮めず、人物・衣装・手の全体へ等比で適用。身長設定ではない。あかり・沙織も女性共通ルールの対象。 |
| 会話表情は腰上 | 制作方針 | 頭〜腰・腰骨と手を含む1024×1024候補。全身表情は必須でない。 |
| 全身通常 | 制作済み候補 | 1024×1536、full/neutral.png。個別画像・寸法は採用待ち。 |
| 腰上書き出し | 制作上の共通規格 | 原本全キャンバスを960四方に収め1024四方の中央へ、32px余白。表情ごとに輪郭でサイズ合わせしない。 |
| 湊左x26%・澪右x74% | 既存表示確認見本の値 | 本編の人物全員の固定位置として採用された値ではない。他人物へ勝手に展開しない。 |
| 湊上12%・幅54%、澪上18%・幅48.6% | 未採用の配置案 | 女性90%という倍率だけ暫定合意。上位置は合意済みに昇格させない。 |
| 素材下端を画面外へ、画像内頭側を維持 | 未採用見本で確認した配置方法 | object-position:center topの見本。全員の頭上の画面座標は未決。 |
| 身長と頭身の作画基準 | 未決・ART-01バックログ | 女性90%を物理身長へ換算しない。 |

## 頭側の基準と見切れ

face-calibration.jsonの通常画像の額〜顎の目視概算：湊y148〜311（163px）、澪y151〜333（182px）。髪の量を除いた概算で、自動検出や全表情の完全一致ではない。
1920×1080見本の会話欄はx5%、幅90%、上端y736・下端1056、高さ320、下余白24。不透明度68%。
現行枠へ正方形PNGを入れると約y853で画像下端が会話欄の中に出る。未採用配置案は下端を画面外へ伸ばす。顔・口元・胸元の手は見え、腰の手や腕の下側は会話欄に隠れる。
顔の位置には生成上の微差があるが、表情ごとに倍率を変えて吸収しない。人物間の頭のサイズ・実身長は未確定。

## 実装適用を確定できる範囲

女性90%を共通暫定倍率として記録できる。画像種別とファイル一覧、同一人物全表情へ同じ倍率を使う制作方針も引き継げる。
各人物の具体的なx/y/幅、未採用PNGの正式採用、本編UIでの見切れはまだ確定できない。既存見本の値を比較用に利用する場合も未採用案と表示する。
素材側の「本編未適用」はこの素材ブランチでの状況。別の組み込みブランチの変更状況を保証するものではない。

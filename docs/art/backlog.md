# 素材制作バックログ

## ART-01：身長・頭身を考慮した人物作画

状態：バックログ・未着手。2026-10-11、ユーザー合意。

目的：同一キャンバスでも素材内の顔・頭・体の比率が異なる問題を、設定と作画の基準から整える。

暫定運用：基準表示倍率100％、女性90％。性別による倍率は制作中の便宜的なルールで、実身長の設定ではない。

実施すること：

- 未決の身長・体格を人物プロフィールで検討し、ユーザーと決める。独断で数値を埋めない。
- 共通の作画スケールと基準位置を用意し、身長・頭身・顔の大きさを反映した全身・腰上素材を制作する。
- 人物内では表情や所作を変えても頭・体の基準を維持する。
- ゲーム画面で人物間の比率と顔・手の視認性を確認し、人物ごとの表示倍率・位置を定める。
- 基準が整った時点で女性一律90％の暫定ルールを置き換え、仕様MDと見本を更新する。

今回の範囲：バックログへの登録のみ。素材再生成、身長設定の確定、ゲーム実装の変更は行わない。

## ART-02：人物仕様とストーリー側の設定同期

状態：同期待ち・未実施。2026-10-11、ユーザー指定。

直人の基本情報は暫定採用とし、素材制作を進める。後で人物仕様とストーリー側の最新設定を照合する。

- 名前・年齢・職業・性格・話し方・関係性を確認する。場面に必要な衣装・所作も照合する。
- 差異と、その差異が画像制作に与える影響を整理してユーザーと調整する。
- 決まった内容を人物別 profile.md に反映し、必要な素材だけ更新する。
- 画像の採用状態とストーリー設定の確定状態を区別する。照合前に同期完了とは記録しない。
- このチャットからストーリーや実装を独断で変更しない。

対象の起点：[直人の人物仕様](characters/naoto/profile.md)。人物が増えた際も必要に応じて同じ手順で照合する。

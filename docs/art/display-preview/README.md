## 見本の条件

- src/features/story/story.cssを直接参照。Zen Kaku Gothic Newも同梱フォントを使用。
- 背景は既存の事務所仮背景を再利用。正式背景として採用するものではない。
- 画像はゲーム候補を相対参照し、元画像をコピー・編集しない。
- 湊は左x26％、澪は右x74％。人物表示と話者表示を連動させない。
- 現行枠：上17％・幅36％・高さ86％。
- 腰上配置案：上12％・幅54％・高さ108％。正方形画像は幅に合わせた等比表示で、下端を画面外へ伸ばす。
- 会話欄：幅90％、高さ320px、下余白24px、不透明度68％。1920×1080基準。
- 表情、配置、会話欄、ガイド、通常の半透明重ね合わせ、表情順送りを操作できる。
- 見本の上部アイコンは簡略線画。上部ボタンと会話欄は本編操作を行わない。文章は表示確認専用。
- 複数の相手、コマンドとの重なり、調査記録、喫煙演出は今回の対象外。

## 確認結果

現行枠へ正方形の腰上画像をそのまま入れると、約y853pxで人物画像が終わり、会話欄（y736～1056px）の中に下端の切れ目が見える。

配置案では人物画像の下端を画面外へ伸ばせる。顔と口元・頬・胸元の手は会話欄より上で読み取りやすい。通常の腰付近の手や組んだ腕の下側は会話欄の裏になる。これは所作をすべて見せる配置ではない。

画像ごとの微細な頭の位置・衣服のしわの差は残る。通常の半透明重ね合わせと順送りで確認できる。身長設定・正式な配置・画像の採用を確定するものではない。

## 再表示・再検証

リポジトリ直下をルートにローカルHTTPサーバーを起動し、docs/art/display-preview/index.htmlを開く。Pythonがある場合は python -m http.server 8765 --bind 127.0.0.1。

再検証はリポジトリ直下で node docs/art/display-preview/verify.mjs。環境変数 SAEKI_PLAYWRIGHT_PATH にPlaywrightモジュール、SAEKI_BASE_URL にサーバーURLを指定する。Chromeは標準のインストール済みchannelを使い、必要なら SAEKI_CHROME_PATH で実行ファイルを指定できる。ゲーム依存へPlaywrightを追加する必要はない。

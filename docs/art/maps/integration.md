# 実地理マップの本編組み込み

最新のユーザー修正：東成ビルサービスも通常のピン表示へ戻した。会社は西新宿六丁目の架空のオフィスビルとし、実在タワーの名称・周辺説明と下部リストをゲーム画面から除去。座標JSONにゲーム用の架空位置（経度139.69355・緯度35.6929）を設定し、実在施設の入居先や住所との対応を主張しない。以下の「会社を下部エリア枠に分ける」記録は履歴。

会社のピン復帰後：回帰199件中134成功・65スキップ・失敗0、5187での地図ブラウザー検証2件、座標定義の整合・型チェック・ビルド成功。実名と下部リストがないこと、会社ピンの位置・選択・移動を確認した。

2026-10-19、ユーザーのシステム組み込み依頼により実装。

## 最新の表示調整

ユーザーの画面確認を受け、地図は中央寄せのcover表示で枠を満たす方式へ変更。画像を縦横に引き伸ばさず、枠からはみ出す端だけを切り抜く。ピンは同じ画像レイヤーに重ね、切り抜き後も地理座標を維持する。「上が北」のコメントと地図画面のライセンス表示を削除。PNGに焼き込まれた表示も原稿SVGから除去した。出典・利用条件は資料と座標JSONに保持し、ユーザーが今後予定している別のライセンス一覧で表示する方針。ライセンス一覧の画面自体は未実装。

以下は初回組み込み時の記録。出典の画面表示と画像全体を収める仕様については、この最新調整を優先する。

表示調整後も回帰199件中134成功・65スキップ・失敗0。5187ポートの専用ブラウザー検証2件、画像と座標の整合確認、型チェック・ビルド成功。更新プレビューは本書末尾の画像を参照。

- `TravelMap` の簡易SVGを実地理版05のPNGへ差し替え。
- 同版の座標定義JSONからWGS84→Web Mercator→画像比率を計算し、事務所・共同ビル・警察署の参照位置にマーカーの中心を置く。
- 3:2の画像とピンを共通レイヤーに配置。ResizeObserverで表示領域に収め、余白があっても位置を合わせる。画像を切り抜かない。
- 会社の番地は未決なので位置を推測せず、地図下の「東成ビルサービス／新宿アイランドタワー周辺」から選択する。現在地表示、画像・説明、移動確定、キーボード操作は他の場所と同じ。
- 未解放の行き先は表示しない。現在地の情報表示は可能だが移動は確定できない。Escape・戻るで元の屋外へ復帰。
- 画像内の小さな出典に加え、読みやすいサイズのOSM出典リンクを設置。
- GameState、SaveData version 2、シナリオノード・移動条件・日時は変更なし。高瀬家と潜伏先の移動先追加はしていない。

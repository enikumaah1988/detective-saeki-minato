## ゲーム素材
実際にゲームで使う画像のみ src/assets/images/ に配置する。
characters/<id>/full/neutral.png（全身通常）、characters/<id>/waist/neutral.png・smile.png 等（会話用腰上）を基本とし、backgrounds、maps、items、cutins、illustrations、ui は必要に応じて追加する。
主要5人の全身通常5枚と腰上38枚を制作。[全身通常](neutral-review.md)、[腰上素材一覧](waist-review.md)。寸法は全身1024×1536・腰上1024×1024の制作上の仮案。個別画像の正式採用は未確認。既存デモ素材と実装上の参照は変更していない。

## 設定資料シートの運用
1. 試作中の確認シートは drafts/ に保存する。
2. 設定資料として採用されたら sheet.png へ移動し、対応する生成条件を sheet-prompt.md に移す。コピーは残さない。
3. profile.md に「設定資料として採用」「ゲーム素材は制作中」など用途別の状態を記録する。
4. ゲーム画像は profile.md と採用シートを参照して新たに制作する。確認シートの切り抜きを完成素材と扱わない。
5. sheet.png の更新時は旧版をGitの履歴で追う。必要になった場合だけ sheets/ に分ける。
現行5人は2026-10-11に設定資料として採用。sheet.png と sheet-prompt.md へ移動済み。ブラッシュアップは同じファイル名で更新し、Git履歴で追う。
あかりも2026-10-11に8表情・手の所作のシートを設定資料として採用。ゲーム用個別素材は未制作。
同一画像を二か所にコピーして維持しない。人物仕様も profile.md を唯一の現行正本にする。

## 履歴・Git
history/ は移行前の判断履歴で更新しない。旧状態より現行プロフィールと本ガイドを優先する。
migration-manifest.json は移行した画像・生成条件の現在の保存先とSHA-256。移行時に全件一致を確認。
production/ は廃止。sources/ は読取専用。
制作は art/<内容> の短期ブランチで行い、画像と仕様を同じPRへ出す。mainへ直接コミット・自己マージしない。
制作資料PNGとゲームPNGはGit LFS管理。取得環境にも git lfs install と git lfs pull が必要。
非公開設定を公開資料や生成プロンプトへ流用しない。移行時点のGitHubリポジトリはprivate。

## 人物の表示倍率：暫定ルール

2026-10-11、ユーザー合意。人物の基準表示倍率を100％とし、女性の立ち絵は90％で表示する。現在の対象は澪。通常と全表情に同じ倍率を使い、人物と衣装・手をまとめて等比表示する。画像ファイルそのものの縮小や、実身長が男性の90％という設定を意味しない。

表示倍率だけの暫定採用であり、個別画像や表示位置の正式採用とは別。澪の見本は基準幅54％×0.9＝48.6％。上下位置は別パラメータで、現状の位置案を維持する。本編への適用は実装側の後続作業。

本来の身長・頭身・顔の大きさを考慮した作画は[素材バックログ](backlog.md)で管理する。

# 直人：ゲーム用腰上素材の書き出し

生成方式：組み込み image_gen。
基準：採用sheet.pngと全身通常から腰上通常を描き、その原本と採用シートを参照して表情差分を制作。
保存：src/assets/images/characters/naoto/waist/<key>.png。
寸法：1024×1024、透過。原本は正方形、キャンバス全体を960×960へ等比調整し、四辺32px余白へ配置。表情ごとの輪郭の大きさを基準に拡大縮小しない。
表情キー：neutral, smile, serious, surprised, worried, pained, relieved, remorseful。
全身通常は別用途の1024×1536。各表情の全身素材は作らない。
個別の顔・頭・姿勢には生成による微差が生じるため、一覧と実際の切り替えで確認する。ゲーム実装・ストーリー設定は変更しない。
素材は確認用候補。採用設定資料の状態は維持する。

# 表情・画像命名フレームワーク v0.2
更新日：2026-10-10
状態：運用案。分類は共通辞書として用意し、人物ごとの採用・必要性と具体的な描画は別途確認する。
目的：人物ごとの表情差分を整理し、生成画像の名前とゲームからの参照を一貫させる。ゲーム実装は変更しない。

## 1. 共通表情辞書
通常は全員必須。その他は全員分を必須にしない。喜怒哀楽は検索・整理の分類であり、ファイル名には分類名を重複して入れず表情キーを使う。
キーは英小文字とアンダースコアのみ。定義が決まったキーを同じ意味のまま維持し、同義語で増殖させない。

| 分類 | 日本語名 | 表情キー | 意図・描画の基準 |
|---|---|---|---|
| 基準 | 通常 | neutral | その人物の普段の顔。必ずしも無表情ではない。鳴海の通常は軽い笑み。 |
| 喜 | 微笑み | smile | 通常から目元・口角がわずかに緩む、小さな好意・気遣い。 |
| 喜 | 喜び | happy | 嬉しさが明確に表れる。笑いの動作は必須ではない。 |
| 喜 | 安堵 | relieved | 緊張がほどける。目元・眉・口元の力が抜ける。 |
| 怒 | 苛立ち | irritated | 不快感がにじむ。口元や眉に力が入るが強い怒りには達しない。 |
| 怒 | 怒り | angry | 怒りが明確。怒鳴る顔が必須ではなく、静かな怒りも含む。 |
| 哀 | 悲しみ | sad | 個人的な悲しさが表に出る。涙は必須ではない。 |
| 哀 | 沈痛 | pained | 重い事実や苦しみを受け止める。泣くより顔が重くなる方向。 |
| 楽 | 楽しげ | amused | 会話や状況を楽しむ軽さ。口を開けた笑いは必須ではない。 |
| 楽 | 笑い | laugh | 実際に笑っている表情。人物に応じた口と目の変化。 |
| 補助 | 真剣 | serious | 重要な話や判断に集中。怒りと区別する。 |
| 補助 | 疑念 | skeptical | 証言・説明を疑い、確かめようとする。 |
| 補助 | 驚き | surprised | 予想外への反応。人物ごとに強弱を変える。 |

共通の表情名でも強度・目線・口の開きは人物ごとに異なる。似すぎる差分は別画像を増やさず兼用候補にする。

## 2. 再利用できる追加表情辞書
固有の演出に必要になった表情も、顔の状態が共通するなら他の人物へ再利用できるキーを付ける。この表は追加候補で、制作必須ではない。

| 日本語名 | 表情キー | 顔の状態・用途 | 現時点の人物候補 |
|---|---|---|---|
| 心配 | worried | 相手を気遣う、不安が目元や眉に出る | 澪ほか |
| 呆れ | exasperated | 困惑やうんざり、軽いため息のような表情 | 湊・奥村ほか |
| 警戒 | wary | 相手の動きや意図を注意深く見る | 鳴海ほか |
| 含み笑い | smirk | 意図を隠した小さな笑い | 鳴海ほか |
| とぼけ・おどけ | playful | 軽くふざけたり、笑って話をそらす | 鳴海のおちゃらけ |
| 冷ややか | cool | 感情を抑えて距離を示す | 鳴海のドライな反応 |
| 煙たさ・不承不承 | reluctant | 素っ気なさ、受け入れたくない気持ちがにじむ | 瀬川の湊への反応 |
| 厳しさ | stern | 境界や要求を明確にする、怒りとは限らない | 奥村・澪の静かな指摘候補 |

「ドライにかわす」は話し方・演技でもある。必ず新しい顔を作るとは限らず、seriousとの兼用や台詞の演出でも表現できる。
追加する前に既存キーで表現できるか確認する。固有キーが必要な場合は、英語キー・意味・共通キーとの差・使用人物を辞書に追記する。


## 保存と更新
人物別の必要性・所作・制作状態は docs/art/characters/<id>/profile.md が正本。
ゲーム用個別素材は src/assets/images/characters/<id>/neutral.png 等。制作資料の試作は docs/art/characters/<id>/drafts/。採用した設定資料は同じ人物の sheet.png。
確認シートを設定資料として採用したら sheet.png へ移動し、プロフィールの状態を更新する。ゲーム用素材は別用途として制作する。
確認シートは1920×1080、背景付き、左に全身、右に4×2の最大8枠。頭～胸・腰まで手を収める。
通常は必須、超過分は基本優先で掲載省略。個別素材は透過・全身、共通寸法は未決。
表情と角度・所作は別管理し、全組合せを生成しない。

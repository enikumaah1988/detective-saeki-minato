# 画像素材のディレクトリ構成
状態：2026-10-10、ユーザー承認済み。構成と命名方針を採用。既存素材の移動・改名、ゲーム実装の変更は未実施。

画像素材のルートはimages/。人物名などはディレクトリに持たせ、ファイル名を短くする。

```text
images/
  characters/
    minato/
      neutral.png
      smile.png
      serious.png
    mio/
    narumi/
    okumura/
    segawa/
  backgrounds/
    saeki_office/
      exterior_day.png
      interior_day.png
    siblings_apartment/
  maps/
  items/
  cutins/
  illustrations/
  ui/
```
上記ファイルは構成例であり、実在する完成素材を表すものではない。不要な空フォルダーや画像は先に量産しない。

| ディレクトリ | 用途 |
|---|---|
| characters | 人物立ち絵・表情差分。人物ディレクトリ内で表情名.pngを基本とする。 |
| backgrounds | 場所の外観・室内・屋上。建物の外観もここに含め、場所ごとにまとめる。 |
| maps | ゲーム用移動マップ。 |
| items | 証拠・書類・写真・小物の単体表示画像。 |
| cutins | 思考整理などの人物中心の挿絵。 |
| illustrations | 場面全体を描くイベント絵。 |
| ui | ボタン・枠・アイコン等。 |

建物を単独の切り抜き素材として使う場合に限り、buildings/の追加を検討する。
衣装・角度・所作の差分は必要になった段階で人物ディレクトリ下の階層を追加する。具体的な追加階層は現時点で未決。同じ表情名.pngを使える構成にし、長い名前へ戻さない。
表情キーはexpression-framework.mdの辞書を参照する。

## 制作資料との分離
- images/：正式採用したゲーム用画像を配置するためのルート。
- production/：プロフィール、表情辞書、台帳、生成条件、試作・比較画像・旧版を保持する。
- 試作採用はゲーム用完成素材の正式採用と区別する。現時点の全身試作を勝手にimages/へ移して完成扱いしない。
- 試作には版番号を付けて保存し、既存ファイルを黙って上書きしない。ゲーム用ファイル名から版番号は外し、どの制作版を採用したかを台帳に記録する。
- 将来images/の採用画像を更新する際は、差し替えのユーザー承認、旧版保存、台帳更新を行う。
- 同期参照のsources/は変更しない。

## ゲームとの連携
人物キー＋表情キーから、例としてimages/characters/minato/smile.pngを参照できる。
必要に応じて採用素材の対応表を併用する。未制作表情や兼用先は別途明示し、存在しない画像を読み込まない。
本資料は素材整理の基準。既存ゲームのsrc/assets/cutins/等の配置先・実装を変更する指示ではない。組込み時に既存仕様と整合させる。

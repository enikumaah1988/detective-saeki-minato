## 地理と正確さの範囲

OpenStreetMapの実際の道路中心線・地上鉄道・建物輪郭・公園等を、Web Mercator（EPSG:3857）で描画。生成AIで道路や建物の形を再構成していない。画像の上が北、右が東。概ね東西約1.72km・南北約1.14kmの範囲。東西南北端の厳密値はJSON参照。

新宿駅西側・西新宿6〜8丁目・新宿中央公園北部が入る。青梅街道、税務署通り、新宿駅側の線路、公園と都庁付近の関係を[国土地理院の標準地図](https://maps.gsi.go.jp/)と目視照合した。照合用は [GSIタイル結合画像](gsi-reference-mosaic.png)。納品PNGに国土地理院のタイル画像は含めていない。

OSMの位置精度・収録漏れや更新時差を超える測量精度は保証しない。地下・屋内・地階等の通路は省略。道路幅・線幅は地図表示のための記号化で、実測幅そのものではない。建物の模様と軽微な影は作画表現であり、実在屋上設備の再現ではない。画像の筆致・質感で座標を変形する処理は使っていない。

## 作風の照合結果

参照：`src/assets/images/characters/minato/waist/neutral.png`、`src/assets/backgrounds/office-day.png`、共通の手描き劇画調ガイド。

| 観点 | 評価・調整 |
|---|---|
| 色味 | 湊の墨色の服、事務所の灰青色・木部に合わせ、チャコール・暖灰・控えめな褐色・濁った緑を使用。ゲームの低彩度の基調と整合 |
| 地図としての読みやすさ | 建物輪郭と道路を分離。絵画的な立体化を抑えて、後からピンを置く面を確保 |
| 手描き感 | 顔料のムラと細い陰影を追加。質感用の抽象画像だけimage_genで制作し、地理の線は固定 |
| 残る差 | 人物画より輪郭が均一で、地図らしい図案性がある。人物と同じ筆の荒さを全面に適用すると細街路が読みにくくなるため控えめ。完全な劇画の一枚絵と同じ描画ではない |

判断：配色・明暗・大人向けの落ち着きは本編に合う。ナビゲーション用の図としての作風であり、作画の最終的な好みは比較シートで確認できる。画面の縮小表示・ピンを重ねた実ゲーム表示は未検証。

## 検証

5515本の建物・道路・鉄道パス、33003頂点を取得データと比較。最大差はSVGの小数丸めによる0.000689ピクセル未満。元データの測量精度を証明する検証ではなく、取得後に形を変形していないことの検証。PNGの寸法、北上の方位、主要参照点が画像内にあることも確認。ゲーム実装変更なしのため本編テストは対象外。

再生成：`render_map.py`でSVGを生成し、SVGをsharp等で2400×1600 PNGへ描画する。検証は `validate_map.py`。Pythonは標準ライブラリのみ。納品PNGはBundled Nodeのsharpを使用し、不透過RGBとして書き出した。
